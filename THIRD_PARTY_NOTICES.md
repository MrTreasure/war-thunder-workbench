# Third-party assets

Language flags are unmodified SVG images loaded directly from the [Gaijin common menu](https://store.gaijin.net/), using its original `https://login.gaijin.net/gcm/flags/flag_*.svg` addresses. Sources, checked file hashes and sizes are recorded in `data/language-flags-provenance.json`. These images remain the property of their respective rights holders and are not covered by this repository’s MIT code license. They are not bundled as local copies.

## Owned vehicle marker

The spade uses the original War Thunder game UI asset `item_icon_elite.svg`, through the existing public game asset archive, pinned to commit `ea96f3af75afe1d858f80ac13f212db218bc69ca`. Gaijin retains rights to the original game asset; the archive/CDN is not a Gaijin service. Source, byte count, SHA-256 and application-specific ownership meaning are recorded in `data/account-workspace.json`. It is not included as a local image copy or redrawn.
