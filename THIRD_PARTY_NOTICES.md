# Third-party assets

Language flags are unmodified SVG images loaded directly from the [Gaijin common menu](https://store.gaijin.net/), using its original `https://login.gaijin.net/gcm/flags/flag_*.svg` addresses. Sources, checked file hashes and sizes are recorded in `data/language-flags-provenance.json`. These images remain the property of their respective rights holders and are not covered by this repository’s MIT code license. They are not bundled as local copies.
