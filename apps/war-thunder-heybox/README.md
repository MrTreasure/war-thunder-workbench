# 战雷工作台 · 黑盒工坊

独立的 Android／iOS 小程序子应用，提供载具与配件研发、战绩查询、账号参考价值、单车成就和个人战报。网页站点及其平台绑定独立维护，根目录规范见[文档索引](../../docs/README.md)与[style.md](../../style.md)。

## 版本与发布状态

本地包版本为 **0.1.9**，SDK 固定 **0.9.3**。包版本不等于线上版本。最后保留的2026-10-26回执为：0.1.9提交审核、自动发布关闭，0.1.8已撤回，线上为用户手动发布的0.1.7。本次只整理文档，未联网查询或更改平台状态；后续以官方后台实际读回为准。

远端项目已有绑定，不重复创建。Android／iOS 范围不使用手游 ID 冒充 PC《战争雷霆》关联，平台未确认的能力不声明为可用。

## 开发与检查

在仓库根目录安装固定依赖并准备生成资料：

```sh
pnpm install --frozen-lockfile
node scripts/prepare-data.mjs
pnpm --dir apps/war-thunder-heybox run dev
pnpm --dir apps/war-thunder-heybox run typecheck
pnpm --dir apps/war-thunder-heybox test
pnpm --dir apps/war-thunder-heybox run build
```

网页国家资料已升级为 schema 4／CSV JS。子应用的构建校验仍保留旧 JSON 国家模块和 `vehicle-facts` 约定；下次构建发布前须核对并适配，不能将2026-10-26的历史通过结果套用到当前国家包。本文不宣称这次重新构建或提审成功。

构建不得包含浏览器评分运行时、WASM、源码映射、独立业务资料 JSON、网页专用模块或 Browser Mock 适配层。SDK 平台要求的 manifest 是独立 JSON 的例外。

## 共享组件与数据

- 科技树画布及 `VehicleTile` 与网页共用，不复制另一套卡片；保留真实拥有状态、官方图片、稳定载具 ID、币种与整包价格语义。
- 配件使用共享布局；单车成就、个人战报、请求和风格使用网页共用生成链路。评分与文案来自同一个私有后端，不在客户端计算或推断。
- 详情、筛选、估值依据、协议与账号关联采用带返回的独立页面。字体与缩放比例沿用共享规范。
- 科技树双指围绕手势中心缩放，单指平移；应用内全屏保留退出和返回。安全区域来自 SDK 窗口信息，不向宿主胶囊注入控件。

## 网络与账号

业务 API 固定为 `https://api.mrtreasure.cc/wt-stats/v1/`，通过官方 SDK 网络能力访问 Cloudflare；不使用 NAS、LAN 或个人端口作为超时回退。开发进程的 IPv4 优先只影响本机工具，不改变正式业务通道。

小程序官方授权码只交给自有服务换取会话。已有网页账号通过用户主动发起的关联码确认，不能按昵称或邮箱自动合并，也不虚构网页 OAuth 入口。服务密钥与平台凭据不进入前端、构建包或日志。

启动和返回前台核对当前账号，真实切号丢弃旧私人响应；同账号复核保留当前页面与查询。查询提交仅在受控网络失败场景按原标识核对，授权及保存操作不盲目重试。

头像优先展示小黑盒已授权资料，不提供修改入口，不以网页头像覆盖。关联身份 ID 与个人主页数字 ID 分开，官方未提供的 ID 不猜测。

## 图片与原生能力

导出成品仅在客户端生成，不上传保存。原生分享使用公开的 `share.screenshot`；水印区保留64逻辑像素，深色背景采用对应水印主题，不按 DPR 重复乘坐标。SDK 返回不透明值不能解释为保存相册或发帖成功。

权限声明、审批回执与待验收范围见[权限清单](docs/permissions.md)。本地声明不是平台批准，Browser Mock 不是原生授权或真机图片验收。官方远程预览信息也不等于任意自制二维码已被客户端支持。

图标与封面使用既有官方素材裁切合成，来源及哈希保存在 `data/heybox-branding.json`；`prepare:branding` 可复现。发布需用户授权，自动发布保持关闭，不因文档更新撤审或重新提审。

## 预览与交付

根目录 `pnpm run build:heybox-preview` 可生成独立浏览器支持页，采用隔离预览存储和原生能力适配层，不覆盖工作台主入口，也不冒充小黑盒真实授权。当前国家格式的兼容性仍须先处理。

默认完成代码检查后给用户预览地址，不主动运行截图或全量边缘验收。仅明确要求时再区分浏览器、SDK Mock 与真机验证；原始截图、测试资料及发布回执只留在本机忽略目录。
