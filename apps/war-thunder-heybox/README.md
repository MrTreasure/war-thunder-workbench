# 战雷工作台 · 黑盒工坊

独立的小程序构建，保留载具研发、配件研发、战绩查询、参考估值和个人战报。网页正式站和国际站的绑定保持独立。开发子进程使用 IPv4 优先，减少当前开发机 IPv6 出口问题的影响；公开网关仍有间歇性连接失败，真机网络单独验收。

## 开发

在仓库根目录安装：`pnpm install --frozen-lockfile`。

```sh
pnpm --dir apps/war-thunder-heybox run dev
pnpm --dir apps/war-thunder-heybox run typecheck
pnpm --dir apps/war-thunder-heybox run build
```

远端项目已经绑定，不重复创建。SDK 固定为 0.9.3，预览声明为 Android / iOS，真实设备验收仍待完成。游戏搜索确认 PC《战争雷霆》的候选 ID 为 `236390`，但当前远端预检返回“关联游戏不存在或已隐藏”。手机版预览暂不声明游戏关联，待平台确认后恢复，不以手游候选替代。网络仅申请自有域名 `api.mrtreasure.cc`；2026-10-25 已读回普通网络权限为批准且生效，不包含官方域名能力。真实接口与图片展示仍需客户端验收。

## 账号接入

- 小程序通过官方 `auth.login()` 获取一次性授权码，仅交给自有服务换取工作台会话。服务端密钥不进入项目、构建包或日志。
- 已有账号从网页登录后主动关联；网页关联码由小程序确认。新身份须明确选择创建账号，不按昵称自动合并。
- 本地会话同时保存 `accountKey`，启动、返回前台和切号时核对；确认前不展示旧账号资料，不使用 Host Cookie 恢复身份。
- 接口请求仅使用 SDK 的网络能力，不自动重试授权或保存操作。查询提交只在网络异常时用原请求标识有限核对重试，服务端按账号及请求标识去重；长查询使用现有任务接口，不在客户端计算作战效率。

## 当前进度

首版移动界面已整合研发、战绩和账号三个入口，研发画布复用主分支；估值和战报从战绩进入。图标和封面由既有官方素材裁切合成，来源见 `data/heybox-branding.json`。计算包不包含 WASM；作战效率只展示服务端结果。

本地手机调试要求同一局域网。异地验收使用官方远端版本预览：`hb-sdk remote deploy --release-note "移动端预览"` 上传并提审，默认不自动发布；通过 `hb-sdk remote preview 0.1.1` 取得当前版本预览信息。预览权限按平台白名单控制。网络权限尚未批准时，远端版本的登录、战绩等接口以及外部图片可能不可用，不能将本地临时权限当作线上批准。

构建门禁验证十个国家及十份展示资料的懒加载文件、哈希、无独立数据 JSON 和无 WASM。界面及真实小黑盒授权仍需人工真机验收，浏览器模拟不代表真机通过。

- “体验工作台完整能力”指向现有 QMuse 正式站，提供真实链接和可复制地址，不猜测宿主跳转协议。
- `pnpm --dir apps/war-thunder-heybox test` 的 17 项测试覆盖账号切换、同账号恢复、游客票据、JSON 解析、HTTP／Host 错误、任务结果读取、幂等重试与固定 API 通道。
- 已按本项目授权使用 Playwright 在官方 Browser Mock 验收 Android／iPhone 尺寸：安全区域、退出载具选择、独立详情页、共享载具卡片、官方图标与主站入口通过。实际匿名搜索与战绩资料有成功记录，但重复流程出现网关连接错误，查询稳定性未通过；未执行真实账号授权和 AI 战报生成，不代表真机验收通过。截图与完整验收报告只保留于本机忽略的 `artifacts/`。

正式版业务 API 仅为 `https://api.mrtreasure.cc/wt-stats/v1/`，经 Cloudflare 转发；构建门禁禁止 NAS 直连域名、局域网 API 和个人直连端口，网络异常不切换直连。

## 静态验收预览

根目录运行 `pnpm run build:heybox-preview`，生成独立浏览器预览及截图验收页。浏览器入口复用小程序页面和共享组件，只替换原生能力适配层；保持游客身份，不模拟小黑盒授权或账号合并。研发计划使用隔离的预览存储前缀，业务请求仍仅走 CF API，并禁止重定向到其他入口。

产物位于忽略的 `artifacts/heybox-static-preview/site/`，发布为既有 Render 应用的支持页，不覆盖其主入口。验收截图按明确清单取自本机记录，不上传日志、凭据或整个 artifacts 目录。正式小程序构建检查会阻止浏览器适配层混入。


## 头像与当前提审范围（2026-10-25）

小程序只展示 `user.getInfo()` 返回的当前已授权小黑盒头像，不提供头像修改、选择或上传入口；网页选定头像与小程序展示相互独立。头像读取失败时使用账号图标，不回退成PC头像。账号切换时丢弃旧资料。

服务对象为《战争雷霆》PC版（平台查询确认 appid 236390），不是手游。平台预检要求声明桌面平台后才允许 bindAppIds；本小程序只面向 Android/iOS，因此保持游戏工作区关联为空。自动发布保持关闭，提交审核与真实客户端验收分别记录。

2026-10-25 提交读回：0.1.2 为 `auditing`，自动发布关闭；当前线上仍为0.1.1。新版本已移除小程序头像编辑。17项测试与SDK Mock界面检查通过，真实授权及查询稳定性仍须客户端复核；不能将提审成功当作真机验收通过。
