# 账号功能验收

入口保持在所有页面右侧的共享账号控件。账号窗口通过 `https://api.mrtreasure.cc` 的现有 Cloudflare 入口访问。

## 手动验收

1. 点击登录，确认独立窗口显示研发工作台、登录及注册入口，并可加载人机验证。
2. 使用已有账号登录，确认原来的账号、额度及权限保持一致。
3. 注册：发送验证码，检查收件箱和垃圾邮件；输入验证码及至少 8 位密码，完成注册并自动登录。
4. 找回密码：完成邮箱验证并重置；使用新密码登录，确认旧会话已失效。
5. 重复发送验证码，检查倒计时；连续错误登录后检查限流提示。
6. 打开或刷新页面，有有效恢复凭据时自动恢复原账号；没有有效会话时保留游客访问。旧凭据迁移失败返回原页面、不循环跳转；主动登录和退出后游客访问均正常。
7. 手机或禁用弹窗时，检查整页授权返回，保留原来的科技树、队列或地图深链接。
8. 在另一个标签页退出，确认当前页账号状态随之更新。

## 发布范围

前端通过 `pnpm run deploy:preview` 发布独立 Cloudflare 预览，由用户手动检查。QMuse 应用更新需在确认预览并明确授权后执行；旧 Nginx Muse 路径不是公开入口。后端源码及密钥不进入前端仓库或 QMuse 源码包。完整步骤见[发布说明](../deploy/README.md)。
