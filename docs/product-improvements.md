# 工作台产品优化

## 我的工作台

默认入口为 `#/home`，原 `#/tree` 和 `?guides=1` 地图入口仍可使用。首页展示当前账号的研发计划、出击队列、模拟挂载及关注载具；每组最多四条，保留总数和查看全部入口。游客只读取当前浏览器的游客资料。登录账号切换时不会使用上一账号的摘要。

研发计划按已绑定车库统计未拥有的前置车辆，不展示无法获取的研发点；前置齐全显示正在研发，已拥有目标单独标注。支持手动刷新同步车库。目标复用标准载具卡片，前置数量可打开弹窗按研发顺序展示前置载具及拥有状态。计划可继续到对应国家、军种和目标；挂载按真实保存时间排列。首页不自动加载国家资料，也不查询官方战绩。首页桌面第一排为研发计划与载具关注，第二排为模拟挂载与出击队列。关注载具每页四辆，可翻页；全部关注的当前总价与金鹰总数分别汇总，同礼包去重，缺价/下架/冲突保留未知和已核实小计；折扣标签仅使用当前已确认且适用该载具的活动。最近战绩展示原查询头像，读取本机已有记录，仅恢复快照而不自动发起新查询。今日免费次数与累计通用查询点分开展示，预占额度计入扣减。绑定奖励说明为小黑盒20点、角色10点，实际发奖随后端规则发布启用。没有记录时展示创建入口，不生成虚构推荐或最近使用时间。

## 统一载具信息与操作

详情复用同一操作区：研发载具、研发配件、加入对比，以及确实支持自定义挂载的模拟入口。拥有状态依据当前关联车库；资料核对时间和来源使用已有记录。未知、未提供、解析失败和未采集分别说明，不把缺失值当作零。

## 按用途比较

载具对比可选择机动转场、火力操作、制空飞行性能或对地进出场，实际可选用途取决于军种和可用指标。相关数据前置，摘要只比较同条件已知数值，不生成综合强弱评分。

导弹对比可以突出制导与交战条件或动力与机动。模拟挂载的“我的挂载”增加方案比较，支持二至四套同机型、同资料版本方案。展示公开武器数量、类型、组合重量及适用的炸区估算。跨机型、不同资料版本或无法还原的方案先提示核对，比较本身不会修改保存内容。

## 大厅质量排序

队列大厅、挂载大厅和机型挂载推荐可选择最新发布、最多推荐、质量排序。质量排序先考虑资料核对状态，再结合赞踩比例和评价数量；少量评价保守处理，同等条件近期发布优先。筛选后的全部候选先排序再分页，不将当前页内重排当作全站排序。目录核对不代表当前游戏版本，不展示尚未采集的采用次数。

## 更新与草稿保护

页面在前台低频检查版本，恢复焦点时也会检查；发现新版本后提示手动刷新，失败继续使用当前版本。页面版本与国家资料更新分别处理。队列编辑、未保存或正在保存的挂载、地图编辑和未同步账号数据会阻止更新按钮直接刷新，先完成保存或同步后再更新。

首次使用这一功能需要刷新进入包含更新提示的新版页面；旧页面无法凭空获得尚未加载的新代码。
