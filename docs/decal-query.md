# 贴花查询

前端入口为 `#/decals`，代码和构建已完成；是否已上线以发布版本为准。

- 中文/英文名称、ID 与背景关键词查询；配置分类、资料类型、解锁资料及官图筛选。
- 每页 24 条，URL 保留查询条件；支持浏览器前进/后退。
- 详情展示背景、配置金鹰价、分层任务提纲、原始条件结构及官方公告来源。
- 配置贴花 1531 条、仅语言记录 56 条、官方活动记录 10 条分开展示。公告记录的 ID 是本站观察 ID，不冒充游戏 ID。
- 没有确认官图时保留占位，图片直接使用官方地址。
- 页面懒加载，不加载国家载具文件。请求不携带账号凭据、不消耗战绩或估值额度。
- 浏览器独立 OPFS 查询缓存，校验响应 SHA-256；不支持时降级到同前缀 localStorage。最近缓存可先展示，异步更新失败仍保留。

静态配置不是服务器实时全集，配置价不代表当前价格；没有任务定义不等于免费或无法获得。资料由后端本地数据库分页读取，原包和后端源码不放入前端仓库或发布包。
