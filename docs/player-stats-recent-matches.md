# 近期记录的使用限制

目前接入的官方助手资料包含累计模式、单车记录和官方近期指标，尚未接通带对局时间、地图及胜负的逐场列表。这个结论仅限已验证的接入范围，不代表官方其他服务不存在对应能力。

- 官方近期指标与生涯累计分开展示，不将其命名为“最近几场”。
- 保存两次累计快照后，差额最多表示期间变化，不能还原逐场结果。
- AI 战报只使用当前已有的公开记录；没有逐场依据时，不生成“最近连胜”“本周回升”等判断。
- 不猜测未公开协议、逐场收益或回放对应关系，不绕过登录或访问验证。

当前功能见[战绩与个人战报](player-stats.md)。原始字段调研和样本保留在本机，不作为对外 API 文档。
