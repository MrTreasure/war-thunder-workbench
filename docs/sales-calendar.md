# 折扣日历

日期：2026-10-22。入口：工作台 `#/sales`，桌面与移动导航均可进入。

## 前台

- 默认以月历显示，支持“月历／时间轴”切换；按年份、月份、购买渠道、国家和已公布／预测筛选。月历按北京时间、周一为每周起点，活动以连续横条横跨起止日期，跨周在同一轨道接续，跨月与跨年活动保留在所覆盖的日期。点击横条展开该活动的完整日期与官方来源，点击日期查看当天所有活动。预测采用虚线，参考起止日与宽限时间窗以深浅区段区分。
- 月历横条、时间轴及所选活动详情同时显示文字与颜色：蓝色待开始、绿色活动中、灰色已结束。边界按当前北京时间判断，结束时刻不包含在活动内。预测使用预计起止基准并保留“预计”和虚线标识，不能作为官方活动已开始的证明。
- 日历公开读取在服务端缓存60秒，载具搜索缓存30分钟；前端会话缓存分别10分钟／30分钟，最多48条并合并相同的进行中请求。只缓存成功公开读取，不缓存登录、配额、私人资料或写操作；不清除其他用户存储。缓存日历的服务器时间随经过时长推进，避免把倒计时回拨。后台保存日历设置、收录活动及触发核对时清理服务端公开读取缓存。
- 已核对 36 篇官方公告，录入 39 个 2025／2026 年活动阶段。2025 为去年实绩；2026 已有公告的阶段展示官方时间，其余展示预测。另生成次年预测，便于跨年寻找下一次活动。
- 区分游戏内银狮／金鹰购车、商城单包、捆绑包、高级账号。国家限定活动只代表指定名单，不等于该国全载具参与。
- 关注列表的“＋”与“选择载具”均可打开添加窗口；国家、军种、等级筛选同排展示，名称搜索独占下一行。等级在服务端截取前60条结果之前筛选。搜索国家内金鹰与商城礼包载具并加入关注列表；前后端都只允许 `ge/pack/bundle`，排除普通银狮科技树、联队、交易所及购买方式未知的条目。旧列表中的不适用条目在读取时过滤，不改写原始记录直到用户保存。显示最近可能相关的优惠、北京时间起止及倒计时。明确标注名单待核对或预测；不将可能参与写成确定打折。
- 金鹰原价取自已核验的 canonical 车型数据；礼包原价经已有购买链接关联 `data/store-prices.json` 的 `regularAmountCents`，显示人民币整包金额及核对日期，不拆算单车价值。缺失价格保持 null，前台显示待报价；分值以整数和 BigInt 格式化。
- 页首展示“仅根据往年折扣情况预测，具体数据以官方公布为准。”及“图片和折扣信息均来自盒友整理收集”。点击“折扣日历”标题打开高清参考图，可另开原图查看。图为用户提供历史整理原图的保真放大与清晰化版本，保留原有样式与文字；实际日历日期继续按官方公告核对。
- 通用的预测方法、起止日期含义、参与范围限制及北京时间／结束边界／平台口径，集中在标题下可展开的“日历说明”中。活动详情仅保留自己的具体时刻、历史基准、参与条件和来源；已知通用前缀仅在展示时省略，原始服务器记录保留。预测引用的往年条件标为“历史参与情况”，不作为本年名单。
- 关注列表使用独立 `wt-sale-watch-v1` 浏览器存储，不读取或覆盖队列、研究进度、地图方案。最多60辆；默认显示前5辆，超过5辆可展开全部并收起，折叠只影响展示，不改变保存列表及顺序；保存失败保留当前页面状态并提示。
- 日历只进入时读取服务器排期；搜索框打开后才查询所选国家的载具索引。进入日历不加载任何国家科技树包。
- 倒计时使用服务器时间校正。预测只显示日期窗口与估计提示，不伪装成精确到秒的承诺。前台仅在进入时读取已入库排期，读取失败可重试；不提供刷新活动按钮。官方公告手动查询仅在后台由管理员触发，也可由管理员配置的定时任务执行。不消耗战绩查询额度。

## 高清年历素材

- `data/sale-calendar-reference.json` 保留原图SHA256、处理参数、原始文件和高清版的固定图床地址，仅随日历页面延迟载入。
- 用户明确要求保留原图样式。当前版本直接对850×728原图做4倍Lanczos放大与轻度亮度锐化，输出3400×2912；保持原有表格、配色、文字、布局及比例。页面署名和预测说明位于图片外。
- `scripts/render-sale-calendar-reference.py` 使用Pillow 11.3.0，校验原图哈希后处理像素，不重新排版文字。高清版采用无损WebP，原始PNG也以原字节归档；放大不代表恢复源图丢失的信息。
- Git图床目录为 `MrTreasure/oss-files/war-thunder/sales-calendar/v1/`，当前提交由canonical元数据固定。文件名带SHA256片段，jsDelivr加载失败时使用同一提交的raw地址。
- 图片和折扣信息均来自盒友整理收集，未推定具体作者身份。原图中的历史性概括不替代实际活动的官方公告。

## 预测方法

使用同类、同购买阶段最新的官方历史记录作为基准，推算目标年度的同月日，开始和结束分别给出±4天窗口。黑五按美国感恩节次日；春节按相应农历新年日期平移。窗口为启发式范围，不是统计置信区间。界面分别写明“可能于…开始 / 可能于…结束”，并解释两个范围分别预测端点，不代表从最早开始日到最晚结束日都处于促销期间；不代表某辆载具必定参与。

预测不继承上一年的参与名单为今年事实。已公布日期覆盖同活动同阶段的预测，不因查询失败删除既有事实。涉及新版本排除、商城名单、礼包组合门槛或平台差异时，以当次公告为准，不预测人民币成交价。

## 服务与数据库

沿用独立的 `war-thunder-stats-service`，继续由 Cloudflare 对外：

- `GET /wt-stats/v1/sales`：日历、服务器时间、核对状态。
- `GET /wt-stats/v1/sales/vehicles?country=china&q=...&category=all&rank=VII`：仅所选国家搜索，上限60条。

PostgreSQL 表：`wt_sale_events`、`wt_sale_sources`、`wt_sale_runs`、`wt_sale_candidates`。定时设置位于 `wt_settings` 的 `sales` 键。

首次启动导入 `data/sales-calendar-seed.json`，此后数据库为运行时事实源。种子不覆盖管理页已保存的数据。`sales-vehicles.json` 是服务端搜索索引，使用 `node scripts/prepare-sale-catalog.mjs` 从当前 canonical 车型数据准备，不对外发布整个文件。

## 后台

admin-console 的战雷管理页内增加折扣日历区域，沿用仅超管可进入的已有认证边界：

- `GET /wt-stats-api/admin/sales`：状态、历史运行、待核对公告及事件。
- `POST .../sales/refresh`：立即排队核对官方公告。
- `POST .../sales/settings`：开关与6—168小时间隔，默认24小时。
- `POST .../sales/review`：人工核对时段、渠道、国家、折扣与可选载具名单后收录。

每轮串行访问，至少3秒间隔；扫描最新两页 Shop 公告，每轮最多14篇正文，同一正文6小时内复用。手动触发十分钟冷却，复用进行中的任务；数据库锁防止同一服务多实例重复扫描。

只抓固定官方域名与新闻路径，不接受任意URL。403／429直接停止本轮，不换身份重试。错误记录尝试时间，保留先前有效来源与活动，不把失败写为新核验时间。

新的、单一时段的主要季节促销可自动录入已公布日期，力度和名单不从去年继承。多时段、国家专题或发生正文变化的已核验公告进入待核对列表；管理员可在原文旁填写真实优惠时间。未明确具体载具时，前台提示“可能相关”。

## 加载背景配置

- 默认使用 Sky Odyssey 官方原始壁纸：`data/workbench-appearance.json`；后端同名默认文件与工作台保持一致。官方壁纸页及图片链接核对于2026-10-22，图片HTTP200、JPEG614649字节。
- 后台“战雷管理 → 工作台加载背景”配置主题名称、官方HTTPS图片地址与横纵位置，保存到Postgres `wt_settings.workbenchAppearance`。沿用已验证的超管代理与同源写入限制。
- `GET /appearance` 服务端缓存60秒，前端独立保存最后成功配置5分钟；保存后台设置时清理服务端缓存。后台写入、登录会话与用户配额不进入公开缓存。
- `scripts/prepare-appearance.mjs` 在构建时更新受标记保护的HTML默认主题与启动脚本；加载页立即显示默认或本机保存的官方图片，配置更新异步进行，不阻塞应用。更新图片读取失败保留有效背景，损坏的已存背景回退Sky Odyssey。
- 启动HTML与React加载页共享 `--wt-loading-background-image`、`--wt-loading-background-position`，不读取国家数据。图片保持官方原始HTTPS地址，不归档到本地或代理。
