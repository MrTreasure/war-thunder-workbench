# Workbench languages

The interface supports `zh-CN`, `en` and `ru`. The shared header contains one accessible language menu using `GameSelect`, with native language names in the expanded list and compact indicators on the trigger. Changing language does not remount routes or clear calculator/editor state.

## Sources and state

- UI messages are canonical in `data/i18n.json`, with English/Russian pairs keyed by the existing Chinese message. `t` interpolates explicit placeholders. `localize` is a display adapter for primitive React children and labels; it never changes React elements, form values, identifiers or saved records. Interpolated user values are preserved, not recursively translated.
- `useLocale` subscribes components to a shared external store. `wt-language-v1` is the only new persistent setting. Storage denial leaves the current in-memory choice usable. Storage events synchronize tabs.
- The optional outer `?lang=zh-CN|en|ru` query overrides the saved setting on entry. Changing a query-selected language preserves the current hash route, other query parameters and TanStack history state. Without an explicit choice the default remains Chinese.
- Verified game names come from the existing pinned language CSVs. The Russian column and raw source entries are kept with the existing localization proof. Build gates verify Russian substitutions and keep RP, prices, prerequisites and original source dates separate. No automatic translation service is used.
- Country payloads stay lazy and verified before caching. Local vehicle searches include the original, English and verified Russian names regardless of the selected UI language. Switching language never fetches country payloads, official stats or AI reports. Vehicles prefer a verified Russian name in Russian, then the available English name, then the original name. The stats service's own historical records may only contain the original display name.
- User nicknames, saved lineup/plan names, custom annotations and original AI comments are not translated. Linked guides and original reference imagery retain their source language. These are labelled in foreign-language views.
- Dates and numeric displays follow the selected locale. Calendar dates continue to use Beijing time. Prices remain CNY/GE/GJN as applicable, without currency conversion or changes to integer-cent arithmetic. Foreign-language sale percentages use percentages rather than Chinese discount-fold notation.
- Account authorization windows follow the selected language; this changes presentation only. Their service implementation remains local-only.

## Game terminology and compact labels

Use the verified game localization as the terminology reference, including `mainmenu/btnShop` (Research / Исследования), `mainmenu/btnModifications` (Modifications / Модификации), `shop/battle_rating` (Battle rating / Боевой рейтинг), and the five `mainmenu/*` branch names. Russian compact battle-mode labels use АБ / РБ / СБ; the corresponding full game terms are Аркадные бои / Реалистичные бои / Симуляторные бои. Research Points use Очки исследования (ОИ), and Golden Eagles / Silver Lions use Золотые орлы (ЗО) / Серебряные львы (СЛ). Workbench-specific features such as valuation and research planning use concise descriptive labels, not invented game features. Do not abbreviate verified vehicle names in canonical data; use truncation with the full name available where needed.

Shared selectors use flat charcoal surfaces, a single border and gold selected/focus states. The header language action has no gradient or inset shadow in any state, while its menu keeps an external shadow for separation from the page.

## Layout and verification

Locale rules live in `src/i18n.css` after the shared/mobile styles. Header language controls stay 44 px high, narrow layouts keep the account action at the right edge, dropdown choices show full labels, and compact selected labels may ellipsize. Filters can wrap where appropriate; research canvases, crew strips and existing horizontal pagination keep their established scroll behavior. Exported card text is measured after localization; report text is bounded by its available canvas width.

`pnpm run check:i18n` verifies both foreign translations, placeholder parity, source UI calls, remaining literal JSX text, compact navigation/action lengths and verified Russian vehicle coverage. It is part of `pnpm run check`. Standard type, lint, data, map-editor and build gates still apply.

Manual review remains necessary for actual browser/font layout. Review at 320/375/800/1100/1560 px and with enlarged text: header, page menu, all five research categories, calculator/modification/cart dialogs, lineup drafts/sharing, map editing panels, stats/hangar filters and pagination, valuation sections and exported cards. Radar axes use compact labels with full accessible titles and expanded values; the gate bounds their foreign-language lengths. Switch languages with an unsaved lineup/map draft to confirm state and focus remain usable. Native modal dialogs keep the outside header inert; test dialog updates through a language change in another tab. No browser automation is introduced.
