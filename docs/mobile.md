# 网页移动端操作

适用于浏览器工作台；小黑盒客户端另见[子应用说明](../apps/war-thunder-heybox/README.md)。预览入口：<https://render.mrtreasure.cc/war-thunder-trees/>。

## 当前行为

- 科技树筛选在 800px 及以下收起，粗指针设备放宽到 1100px。摘要保留国家、军种、模式及搜索状态；关闭面板不清空筛选。
- 所有页面共用顶部栏。桌面显示页面链接，移动端使用顶部页面选择器，独立于科技树筛选；可直接进入陆战地图。
- 载具和配件研发使用单列滚动，输入框至少 16px，常用操作至少 44px；详情、购物车与分享窗口不能撑宽页面。
- 队列乘员槽位保持一条横向、不换行的列表，支持滚动、长按重排与键盘操作；新建或编辑仅在保存后持久化。
- 地图的工具与属性面板浮在画布上，不因开关面板改变画布尺寸、相机或标注位置。

## 用户手动检查

可按需选择窄屏、横屏与桌面检查：页面切换和前进后退；筛选展开／收起与搜索定位；研发输入和关闭按钮；队列保存／取消／分享／重排；地图平移缩放、走线显隐与导出。软键盘和浏览器地址栏变化后，关闭与保存操作应仍可触达。

默认由用户在预览中检查。发布命令与代码门禁见[发布说明](../deploy/README.md)，不以自动截图作为交付门槛。
