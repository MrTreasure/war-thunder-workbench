1. **本地采集与准备**：`scripts/collect-vehicle-reference.py` 支持 `--reuse-from`，只复用已验证原件，缺失性能／挂载不能仅因配件或收益齐全而跳过。`scripts/prepare-collected-vehicle-reference.py` 使用 `scripts/wiki-vehicle-reference.py`，`--staging-only` 仅输出候选 patch，不改 canonical；完整性失败保留旧记录。
2. **私有后台采集**：Go 手动详情采集的完整性判断同时检查性能与飞机／直升机挂载，同页补缺；通过既有可信 host bridge 调用同一离线公开页面解析器，避免两套解析口径。候选进入原管理员手动更新流程，携带来源时间与页面哈希。相关后端源码仅在本机维护，本轮已通过 Go build／vet，尚未部署这一后端变更。
