# 生涯战绩与战报预览

本次先确认页面样式，尚未开放新的在线战绩查询、登录或 AI 生成。

- **生涯总览**：切换街机、历史、全真模式，查看场次、胜率、击毁、类型时长和各国拥有载具数量；下方可按型号和军种筛选载具。
- **生成战报**：只选同一模式中战斗场次最多的五辆载具；可切换陆战、航空背景及评价文案风格。
- **真实样本**：ArthurDaynee 的公开资料；页面显示实际采集时间。预览不会继续请求官方数据。
- **评价说明**：目前是根据真实数据写的示例文案，已经明确标注。没有调用 AI，也没有生成或扣减业务额度。
- **待核对玩家**：Starfall 的同名候选尚未确认到用户所说的满级活跃账号。保留待确认状态，不拿其他同名玩家的资料代替。
- **暂不展示**：来源未确认的效率分值、银狮收益、近期时间窗口；未返回的数值显示为“—”。

背景、载具图片和军种图标均引用战雷原有素材。正式战报保存与统一账号登录将在设计确认后接入。

详细规则见[战绩与 AI 战报方案](player-stats-report-plan.md)。

## 预览文件

- 页面源文件：`design-previews/player-stats/`
- 公开资料样本：`data/player-stats-preview.json`
- 样本传输与页面构建：`pnpm run build:stats-preview`，常规构建也会自动执行。
- 构建后入口：`design/player-stats/preview.html`。数据以 JS 发布，不发布独立 JSON。

原始研究响应留在被忽略的 `artifacts/`，不上传。现有应用入口不增加尚未接通的查询按钮。
