# 战绩查询与个人战报

使用入口：正式站的 `#/stats`；独立预览为 <https://render.mrtreasure.cc/war-thunder-trees/#/stats>。操作图片见[使用说明](usage.zh-CN.md)，数据限制见[近期记录](player-stats-recent-matches.md)。

## 当前能力

| 内容 | 说明 |
| --- | --- |
| 生涯与官方近期统计 | 按游戏昵称确认玩家，分模式与军种展示；不同范围保持独立 |
| 官方排行榜 | 独立子页展示官方指标与名次，不把工具评分当官方排位 |
| 单车记录 | 筛选、排序、分页及表格／卡片切换，缺失项保持未知 |
| 完整车库 | 登录关联 UID 后从「出击队列 → 我的车库」进入，包含已拥有但未出击的载具 |
| 账号参考价值 | 保留不同币种、整包价格、来源时间和未核价项目，不代表成交价格 |
| 个人战报 | 选择国家、兵种与模式，基于对应范围 Top 5 生成点评与图片 |
| 单车卡片 | 使用该次公开统计与已核验素材，在浏览器生成分享图片 |

车库中的真实已拥有状态与出击记录、推算前置不同。关联 UID 是防误绑流程，不代表官方所有权认证；不要求玩家提供 Gaijin 密码。

## 缓存与额度

有效缓存优先复用，网络更新失败保留已有资料。缓存时长、每日额度及剩余次数以服务端配置和页面实际提示为准，不在文档固定承诺某个身份无限次或固定冷却小时数。来源时间是实际采集时间，不因重开页面、升级派生评分或修改文案刷新。

## 评分与数据含义

[效率评分](player-stats-efficiency.md)由私有服务统一返回，前端不含公式、WASM 或计算回退。生涯、单车、模式与战报保留同一评分版本。

累计银狮不是当前余额、维修补给后净收益或逐场到账。军种 K/D 使用对应范围的记录；总览、榜单和单车汇总之间的差值不强行凑平。官方近期指标不能冒充最近逐场记录，也不能据此编造“最近连胜”等趋势。

风险昵称按现行审核规则显示为 UID，不在历史、图片、复制或导出中恢复原文。战报输入与生成文案分别审核。

## 图片导出

背景与官方图片来自已登记资源，个人战报及卡片由客户端生成，不上传保存图片成品。AI 文案、报告记录与导出图片是不同对象，不能因图片只在本地生成就声称服务端没有报告记录。

必要图片加载失败必须提示，不能静默漏层。原生小黑盒分享和浏览器 PNG 下载分别验收；浏览器或 SDK Mock 成功不代表真机保存、授权或发帖成功。

账号行为见[账号检查清单](account-acceptance.md)，截图时间与来源见[截图清单](screenshots/README.md)。后端实施记录、调研样本及逐次发布回执不在此前端文档中维护。
