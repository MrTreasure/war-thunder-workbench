# 陆战地图维护


## 入口与资料范围

- 预览：<https://render.mrtreasure.cc/war-thunder-trees/#/maps>；地图改造仍在隔离预览，正式入口待用户确认后切换。
- 地图详情：`#/maps/{mapId}`，支持布局、己方队伍、列表筛选和返回导航。旧 `#/maps?map=...&side=...` 自动跳转；旧根查询 `?guides=1` 仍打开地图，普通首页进入科技树。
- 当前目录包含 55 张地图、309 个任务布局、77 张布局缩略图。原始 2,242 条简报点位保留，显示层可能去重，不将原始记录数当作可见图标数量。
- 推荐走线包含 36 张地图、41 个布局、82 张双向适配 SVG。84 张原始走线中，未收录的 2271 号测试基地两张不映射到其他地图。
- 旧高清图集是独立资料集，包含 43 张原图、20 张栅格走线图；不能与当前地图底图或适配 SVG 按名称自动合并。

## 加载、权限与缓存

运行时经版本化地图 API 读取公开清单、布局、CDN 元数据与攻略摘要；不再导入整份静态地图 JSON。小型走线 SVG 由隔离数据库管理，大体积底图与等高线继续经 CDN 读取。来源原件、未核对正文和采集审计保留在私有资料库，不默认公开。

地图接口固定使用 `/wt-stats/v1/map-data-preview`，与载具资料的正式／预览构建开关独立。该前缀也是国际站当前可用的地图接口；服务端尚未提供 `/wt-stats/v1/maps`，不能因正式站构建而省略地图前缀。

公开快照使用独立 IndexedDB `wt-map-data-cache-v1`。有有效快照先展示，刷新失败保留并提示，不影响国家资料、账号、队列和地图方案。

工作台的推荐走线按钮、列表角标与导出叠加仅超管可见；身份确认前、匿名或普通用户不请求受限走线。外部自有应用可使用独立签发的 `routes:read` AK，权限与持有方式见 API 文档。

走线索引按身份和发布版本复用。进入详情读取当前布局双方的走线，开关仅控制已挂载图层显隐，不取消下载或销毁已验证 Blob URL。返回已加载布局、切换已预读出生侧时使用会话缓存；首次加载仍需要网络。缓存最多保留 24 个上下文，保护当前上下文，切换身份取消在途读取并释放地址，不持久化受限 SVG。

## 图床资源

地图图床为 [MrTreasure/oss-files](https://github.com/MrTreasure/oss-files)，资源目录 `war-thunder/ground-maps/v1/`，主 CDN 为 jsDelivr。固定完整提交 ID 与内容哈希，实际地址从发布清单读取；不硬编码某次提交为永远的现行版本。

仓库总大小不直接决定单文件是否可读；包目录、单文件和整仓回退的区别见 [Git 与 CDN 限制](git-cdn-limits.md)。地图压缩另以实际传输体积、解码和放大效果评估。

WebP／AVIF、SVG 的 HTTP 压缩以及等高线整数差分编码的离线比较见 [地图压缩与等高线数据化](map-image-compression.md)。该评估未更改线上格式，不将普通坐标 JSON 或实验解码器纳入发布包。

依次使用主地址、GitHub 原始地址、记录中已有的 R2 备用。`sha256` 对应主文件，`sourceSha256` 保留原件身份，`fallbackSha256` 对应字节可能不同的备用文件。旧方向错误的 DOM 合成图不能作为缩略图回退。

原始 ZIP、巨大等高线坐标 JSON、采集截图与配准原件不进入前端 Git、QMuse 或静态包。图床只存已确认可公开的素材；不存后端、凭据或玩家生成图片。

## 坐标、点位与版本

底图原点为左上角，世界 Z 增加对应图片向上：

```text
u = (worldX - minX) / (maxX - minX)
v = (maxZ - worldZ) / (maxZ - minZ)
```

屏幕与导出使用完整地图 0–1000 画布。原等高线 SVG 应用一次 `matrix(1 0 0 -1 0 1000)`；底图、原生图标、字母和用户标注不反射。推荐走线用自己的配准矩阵，不再次反射。`crop: null` 表示整图，任务裁切仅限制地图图层，不裁用户标注。

部分导出任务合并 AB/RB/SB 点位。默认占领点按种类、队伍与标签保留首条，出生点只合并坐标完全相同的重复记录。API 原件全部保留；SVG 展示与 PNG 导出使用同一筛选结果。默认点位集不是已核验的各模式实时点位。

参考网格未与实时对局校准；等高线不包含建筑、桥梁或通行性信息，世界 Y 不视作已校准海拔。旧攻略保留作者、年份与原帖，并提示版本及布局差异。

冬季地图仅按 `seasonalVariants` 明确关联的地图及布局复用攻略与同队伍走线；不能猜测相近布局或使用对面路线。用户方案始终按原地图／布局／队伍隔离。

## 绘图与方案

- 主工具为选择、平移、战术线、画笔、形状、标记与文字；战术线和属性面板浮在画布上，开关面板不改变相机或画布尺寸。
- 线和箭头拖动松开即完成，支持端点编辑、拖动空心中点插入拐点、删除拐点与键盘／数值调整；一次完成拖动是一条撤销记录。
- 矩形、椭圆、多边形危险区，狙击与观察标记、文字字体、战术线朝向及曲线样式均保持受控数据。原游戏图标与项目绘制的战术符号分开展示，不宣称军标认证。
- 地图是较大画布中的一层。标注使用完整地图归一化坐标，可在有限范围 -32–32 内伸出地图，平移缩放不改变保存坐标。
- 主工具栏一键清除当前方案全部自定义标注，包括隐藏和锁定项；此操作可撤销，不弹确认，不删除原地图与任务点位。
- 每份方案最多 500 个标注、累计 50,000 个走线点；单条最多 3,000 点，撤销历史 60 步。

命名方案仅保存在 OPFS `wt-map-plans-v1`，按地图／布局／队伍隔离。支持新建、另存为、重命名、切换与删除，删除需确认且至少保留一份。旧 `wt-map-editor-v1:*` 草稿只迁移一次并保留原键，新方案不写入 localStorage，不属于数据缓存。

写入使用串行队列、Web Locks 与新鲜读取；方案或路由切换前完成并保存，撤销记录按方案隔离。配额、损坏或不支持 OPFS 时提示并保留此前文件，不覆盖为新空方案。

## 导入与导出

`.wtmap.json` 是用户可编辑文件，版本 1 保持兼容；导入创建新命名方案，不覆盖已有方案。校验地图／布局／队伍、ID、有限坐标、文字、图标白名单及大小上限 4 MiB；不接受任意图片 URL、字体地址、HTML 或执行内容。

2K／4K PNG 使用当前视窗、同一坐标投影与可见图层，包含地图外标注，不带编辑控件。图层读取遵循 CORS；必要图层失败报错，不静默漏图，支持取消和备用源。SVG 与 Canvas 共用线条几何及受控字体，导出前等待字体就绪。

本地方案与“完成”时异步提交的绘制 JSON 快照分开；完成记录不采集逐笔过程、不上传图片，不能当作云端可编辑方案备份。

## 资料维护与检查

| 资料                                 | 维护输入                                                         |
| ------------------------------------ | ---------------------------------------------------------------- |
| 地图、布局、投影、图片来源与季节关联 | `data/ground-maps.json`                                          |
| 适配路线身份与可信导入 SVG           | `data/map-recommendations.json`、`data/map-recommendations/`     |
| 旧高清图集及摘要                     | `data/map-atlas.json`                                            |
| 补充合集目录与核对状态               | `data/map-collections.json`、`data/map-collection-settings.json` |
| 原游戏图标、项目符号、线型来源与字体 | 地图编辑器对应登记表和受控字体清单                               |

上述文件是规范输入及导入校验依据，不表示运行时将它们作为独立 JSON 或公开走线 SVG 发布。预览控制台维护资源 URL、草稿、核对、发布和服务 AK；正式数据切换仍需用户确认。

重新准备原始导出资料：

```sh
python scripts/prepare-ground-maps.py '<地图解压目录>' '<缩略图解压目录>'
python scripts/correct-ground-map-projection.py --maps '<地图目录>' --thumbs '<缩略图目录>'
python scripts/audit-ground-map-projection.py --source '<地图目录>'
python scripts/archive-ground-map-assets.py --repo '<图床本地工作目录>' --source '<地图目录>'
python scripts/import-map-recommendations.py '<已核对的矢量素材目录>'
```

图床归档脚本不自动推送。确认资源已提交并可读取后，才用 `--apply-ref '<完整提交ID>'` 更新引用；随后检查候选资料，再按授权发布。数据准备不触发网站或数据库发布。

`pnpm run check` 包含地图数据、投影、编辑器、方案及走线检查；`pnpm run build` 检查产物不含独立资料 JSON、公开推荐 SVG 或浏览器评分运行时。界面与实际导出由用户在[独立预览](https://render.mrtreasure.cc/war-thunder-trees/#/maps)检查，发布步骤见[发布说明](../deploy/README.md)。

线型与符号研究来源保留在登记表；交互参考 [tldraw](https://github.com/tldraw/tldraw) 与 [Excalidraw](https://github.com/excalidraw/excalidraw)，不引入整套绘图库或声称符合完整军标。
