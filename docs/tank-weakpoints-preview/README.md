# 坦克弱点图文样例

当前使用独立审阅页，尚未加入双站正式导航。采集来源、公开正文、结构化文字、车型、图片关联和核对状态均持久化到独立资料草稿；待核对内容不更新现行发布版本。

当前已配正面弱点标注的样例为 T-54（1947）、T-62M-1、T-72A、IS-1、IS-2（1943）、IS-3、IS-4M、Challenger Mk.3、Type 90（B）、ZTZ96B、Leopard 2A7V；IS-6、IS-7 已配正面图，但局部推荐部位证据不足，仍为待补。主任务 226 辆中，226 辆已核对 Wiki，49 辆已配主图，9 辆已完成当前证据范围的图解；T-54（1947）另作范围外的历史样例。另有用户追加的 4 款虎王，量产炮塔型已配正面图及条件性点位；早期炮塔型待补清洁主图，Sla.16 与 105 毫米型只有 Wiki 资料。其余 Wiki 记录标明待补图，不计作完成图解。型号、来源条件、文字、装填时间和标注坐标维护在 `data/tank-weakpoints-samples.json`。不会把 T-54 的不同年份型或 T-62 的不同改型合并成同一张通用弱点图。

图片来自已核对的 B 站游戏画面及论坛原始截图；主图与仅作来源的外观、侧视和透视图分别登记。分析阶段使用 720P，展示帧保留视频实际可用的原生 1080P 或 4K；构建仅裁切原始像素并无损转换为 WebP。网页标注为独立可交互图层，圆形编号桌面 18px、移动端 16px，保留 44px 点击区域；完整原始帧保留作者水印、弹种、距离、版本与界面提示。未使用 AI 生成装甲结构或程序重绘坦克。

## 证据口径

- Wiki 支持车型、基础装甲、复合／加装装甲和结构说明；基础厚度不等于等效防护。
- 视频保留具体弹种、距离、视角、游戏版本和逐帧时间。防护预览、模拟毁伤与实战击杀分别描述。
- T-54 的直接击穿与 Wiki 提及的跳弹陷阱不可混作同一种机制。
- T-62M-1 的 BDD 覆盖区与未覆盖区分别判断；不借下首取样结果推断整个炮塔。
- T-72A 样例不以 Wiki 面板值确认作者口述的局部等效厚度，也不承诺任意距离穿透或必然殉爆。
- 视频版本按片段分别保留：早期三款样例为 2.51.0.65，新增 IS-2（1943）及 IS-6 片段为 2.49.0.98；Wiki 页面版本为 2.59.0.92。未在当前游戏客户端复测。

采集使用 Playwright，串行操作间隔不少于 8 秒，原始页面、截帧与逐帧证明留在忽略的本地 `artifacts/` 中。构建器检查来源型号、实际帧时间、版本、图像尺寸与标注边界；不发布原始页面、登录态或独立 JSON。

## 采集与数据验收分工

采集、离线视频解析、Wiki 核对和数据录入按功能分工，最多并发三个子 Agent，模型使用 gpt-6.1-sol medium。主 Agent 验收精确改型、等级范围、来源版本、主炮装填、图片哈希、裁切坐标与数据库关联；不做页面验收。证据不足保留待补状态，不以已采页面数、已入库记录数或已配图数替代完成图解数。

优先采集多车型弱点合集，以整片建立车型与时间分段索引，再按每批 10～20 段解析、入库和验收。连续正常播放字幕保留实际观测时间；口播族名与已确认目标标题分别记录。已采原件先复用，缺主图的车型先展示已核对的文字、测试案例和视频跳转，后续补图与标点。

M1 Abrams、IPM1、M1A1 SA、TTD、Challenger Mk.3、Challenger 2 TES 已接入 8 个案例和 11 条建议；Mk.3 已补俯视正前方的可见炮塔区域图，M1、IPM1、M1A1 SA、TTD、Challenger 2 TES现已补原片正面绿色防护图。M1 的游戏界面为 300 米／476 毫米，与作者烧字 500 米的矛盾独立保留；IPM1 防护比较与负向演示分开。独立主图来源与试射来源分别绑定，不把拍摄外观时未显示的炮弹条件补成已知。
