# 坦克弱点图文样例

当前使用独立审阅页，尚未加入双站正式导航。采集来源、公开正文、结构化文字、车型、图片关联和核对状态均持久化到独立资料草稿；待核对内容不更新现行发布版本。

当前已配正面弱点标注的样例为 T-54（1947）、T-62M-1、T-72A、IS-1、IS-2（1943）、IS-3、IS-4M、Challenger Mk.3、Type 90（B）、ZTZ96B、Leopard 2A7V；IS-6、IS-7 已配正面图，但局部推荐部位证据不足，仍为待补。主任务 226 辆中，133 辆已核对 Wiki，24 辆已配正面图，9 辆已完成当前证据范围的图解；T-54（1947）另作范围外的历史样例。另有用户追加的 4 款虎王，量产炮塔型已配正面图及条件性点位；早期炮塔型待补清洁主图，Sla.16 与 105 毫米型只有 Wiki 资料。其余 Wiki 记录标明待补图，不计作完成图解。型号、来源条件、文字、装填时间和标注坐标维护在 `data/tank-weakpoints-samples.json`。不会把 T-54 的不同年份型或 T-62 的不同改型合并成同一张通用弱点图。

图片统一采用 B 站视频中的载具正面画面。分析阶段使用 720P，展示帧保留视频实际可用的原生 1080P 或 4K；构建仅裁切原始像素并无损转换为 WebP。网页标注为独立可交互图层，圆形编号桌面 18px、移动端 16px，保留 44px 点击区域；完整原始帧保留作者水印、弹种、距离、版本与界面提示。未使用 AI 生成装甲结构或程序重绘坦克。

## 证据口径

- Wiki 支持车型、基础装甲、复合／加装装甲和结构说明；基础厚度不等于等效防护。
- 视频保留具体弹种、距离、视角、游戏版本和逐帧时间。防护预览、模拟毁伤与实战击杀分别描述。
- T-54 的直接击穿与 Wiki 提及的跳弹陷阱不可混作同一种机制。
- T-62M-1 的 BDD 覆盖区与未覆盖区分别判断；不借下首取样结果推断整个炮塔。
- T-72A 样例不以 Wiki 面板值确认作者口述的局部等效厚度，也不承诺任意距离穿透或必然殉爆。
- 视频版本按片段分别保留：早期三款样例为 2.51.0.65，新增 IS-2（1943）及 IS-6 片段为 2.49.0.98；Wiki 页面版本为 2.59.0.92。未在当前游戏客户端复测。

采集使用 Playwright，串行操作间隔不少于 8 秒，原始页面、截帧与逐帧证明留在忽略的本地 `artifacts/` 中。构建器检查来源型号、实际帧时间、版本、图像尺寸与标注边界；不发布原始页面、登录态或独立 JSON。

```sh
node docs/tank-weakpoints-preview/build.mjs
node --check docs/tank-weakpoints-preview/preview.js
```

只将构建结果中的 WebP、哈希 CSS／JS、同源游戏符号字体和 `weakpoints-preview.html` 发布到既有 Render 预览目录，先资源、后 HTML，保留工作台入口和旧哈希。审阅页不发起账号或业务 API 请求。后续接入时需沿用车型唯一 ID，并分开保存来源、提取文字、条件、证据类型、标注与版本；年代分类与 BR 筛选独立维护。

## 2026-11-02 呈现调整

右侧展示 Wiki 阅读要点、主炮装填、视频测试车辆与炮弹，以及视频攻击位置／建议。测试车辆与炮弹对应各自证据帧；与正面主图不同时间时提供独立测试链接。完整条件、适用范围和逐条核对不作为阅读面板展示；来源证明保留在本地原件和 canonical 记录。视频的推荐与演示位置分别标注，不将演示自动描述为作者明确推荐。

装填取自主炮段落而非机枪：T-54（1947）9.7 → 7.5 秒、T-62M-1 10.4 → 8 秒（基础乘员 → 王牌乘员），T-72A 自动装弹机 7 秒。构建器按已存官方 Wiki 原件校验对应主炮和时间。

## 图床与持续采集

- 独立图床：[MrTreasure/war-thunder-weakpoint-images](https://github.com/MrTreasure/war-thunder-weakpoint-images)，仅上传 WebP；完整视频帧和展示裁切均使用无损 WebP。原始 PNG 不进入该仓库及分支历史。
- 固定版本、CDN、GitHub raw 回退、SHA-256、字节数和来源帧哈希维护在 `data/tank-weakpoint-assets.json`。构建按实际字节校验并优先使用固定图床地址；图片失败时只尝试登记的回退。
- 新增图片仅固定新资产版本，路径与字节均未改变的旧图片保留原 commit 和 CDN 地址，复用已有缓存。
- 范围按游戏 Rank VI/VII/VIII，只将中型／主战坦克和重型坦克共 216 辆纳入主任务，另补 10 辆较低等级的苏联 IS 系列，共 226 个目标。107 辆轻坦／侦察车只在找到专门弱点解析视频并核对后作为可选补充，不按各国逐辆搜索。目标数量与已核对、已配图数量分别记录，不能将范围清单当作完成数量。
- 筛选支持国家、游戏等级、二战／冷战／现代及 IS 系列补充。特定改型的图片、主炮装填和文字分别保存。
- 所有公开采集资料都要入库，包括无足够证据、待补图或有限制的候选；保留状态和限制，禁止以无图、未核对记录充作完成攻略。登录态、凭据和登录后个人导航不入资料库。

## 2026-11-02 筛选与图片命名

国家、等级、年代、车型采用与科技树一致的紧凑下拉交互，箭头使用同一 SVG 几何；“全部国家”不显示国旗，其余国家触发器与展开选项均使用 `data/flags.json` 中的官方国旗地址，国家名来自 canonical 清单。IS 系列另含开关保留。

图床图片命名为国家英文简称、完整英文型号和视角／时间，例如 `USSR-IS-3-front.webp`、`USA-M1A1-Click-Bait-01m10s.webp`，文件名不使用哈希；哈希只作数据校验。未核实车型的素材留在资料草稿中，确认后再按具体型号归档。

## 采集与数据验收分工

采集、离线视频解析、Wiki 核对和数据录入按功能分工，最多并发三个子 Agent，模型使用 gpt-6.1-sol medium。主 Agent 验收精确改型、等级范围、来源版本、主炮装填、图片哈希、裁切坐标与数据库关联；不做页面验收。证据不足保留待补状态，不以已采页面数、已入库记录数或已配图数替代完成图解数。

优先采集多车型弱点合集，以整片建立车型与时间分段索引，再按每批 10～20 段解析、入库和验收。连续正常播放字幕保留实际观测时间；口播族名与已确认目标标题分别记录。已采原件先复用，缺主图的车型先展示已核对的文字、测试案例和视频跳转，后续补图与标点。

M1 Abrams、IPM1、M1A1 SA、TTD、Challenger Mk.3、Challenger 2 TES 已接入 8 个案例和 11 条建议；Mk.3 已补俯视正前方的可见炮塔区域图，其余正面图片待补。M1 的游戏界面为 300 米／476 毫米，与作者烧字 500 米的矛盾独立保留；IPM1 防护比较与负向演示分开。独立主图来源与试射来源分别绑定，不把拍摄外观时未显示的炮弹条件补成已知。

## 多片段测试条件

视频建议分别关联已核对的攻击车辆、炮弹和具体片段；主图中的测试条件只代表该主图片段。IS-3 的 17:00／17:02 为 M4A2（76）W／M62，17:20 猎虎装药弹演示对应的是 IS-4M。虎王量产型主图 M61 为不足穿的负向演示，后续 T34／T14E3 才对应条件性正向演示，不能将两者混为同一测试。未核实的片段版本和条件保留未知。

资料构建分别定位精确主炮与对应装填段，支持武器列表中导弹先于主炮的页面。个别 Wiki unit 标识的大小写差异显式保留，并继续校验车型；不得把其它改型当别名。

## 测试炮弹展示

测试炮弹同时展示原片段型号、经来源核实的弹种类型和面板穿深，并保留对应射击距离。不同测试片段的条件分别展示；不能把 Wiki 零距离数值补到视频其他距离。未显示或未核实的穿深保留未知，不补零。筛选沿用科技树的紧凑下拉、Chevron 和状态样式，外侧可见标签移除，屏幕阅读器标签保留。

## 非苏系图解增量

标准 Type 90（B）、ZTZ96B、Leopard 2A7V 各自保留原始视频、主图和独立测试条件，不沿用到富士型或其它改型。日本主图使用真实4K原件，裁图1200×860；中国与德国按原生1080P裁切，不放大冒称4K。90式左侧油箱后效提醒与正向乘员区域分别记录；96B左右车灯是同类弱区的两个位置，不按标点数增加攻略数量；豹2炮闩失能与首下穿透也分别说明，不保证击杀。

## 苏系 IS 增量与独立主图来源

IS-4M 保留 1026 秒清洁正面和炮管下方小方格的条件性标注；T34／T14E3 的后效提醒与猎虎／PzGr. 的高毁伤演示分别绑定。IS-7 保留 1062 秒正面、1070.033 秒 D-54 破甲弹原标签案例，规范弹药型号与细分弹型尚未确认；该段没有具体局部推荐，保持无标点。1075 秒已切换 T-10A，不归入 IS-7。

Challenger Mk.3 主图来自独立视频的高俯视正前方，仅标可见的炮塔画面左侧区域；试射建议仍来自原弱点视频。主测试跳转优先使用案例自身来源，避免跳到外观视频的错误时间；未显示的首下不作标注。

## 绿色防护分析证据与整体打法

IS-4M、IS-7 的作者整体弹种建议在阅读区单独保留，可不绑定未发生的独立试射。两车可在外观与防护分析原帧间切换；防护分析视图同步显示该原帧的攻击车辆、炮弹、距离和穿深，并提供高清原帧链接。IS-7 已有 D-54 破甲弹正面大面积绿色区域，1070.033 秒版本单独核为 2.51.0.65；IS-4M 已有 T14E3 APCBC 的局部绿色对照，原片这段没有钢针或破甲弹实测绿图，继续补充。截图保留原始颜色与视角，不生成或重绘绿色区域。

Challenger Mk.3 现有左侧炮塔区域保留为部分正面攻略，其他前方区域仍在补证，不计入完整图解数。

Mk.3 另提供原弱点视频中 JM33／500米／472毫米的正面防护分析视图，展示该案例的绿色区域。各证据图先显示原生裁图，可打开未裁切高清原帧；裁图与原帧均按各自固定资产校验，不改原始着色。
