# 玩家勋章详情

- 战绩页头像旁及完整勋章列表中的图标均可点击放大。详情使用共享原生 Modal，展示原图、名称、国家、获取目标、附加条件、模式进度倍率及来源链接。
- 勋章归属仍仅来自玩家详情接口。图标加载失败不减少完整列表中的已获勋章记录；详情保留文字并提供图片重试。
- `data/player-medal-details.json` 为公开游戏资料，不含玩家记录或后端实现。详情组件及这份资料仅在点击勋章后加载，Vite 将其打包为 JS。
- 资料固定到与 `data/player-medal-images.json` 相同的完整提交。保留三个原始文件的 URL、SHA-256 和字节数；这是该版本配置的中文整理，并非游戏界面文字的逐字复制。
- 目前包含 258 枚勋章，其中 1 枚没有常规获取条件。勋章专用语言表未提供非空背景说明。未知信息不补零，也不推断获取时间、个人进度或活动当前可用性。
- 内部匹配等级不转换为未经核实的 BR；特殊距离条件和高级载具适用范围明确保留待核实提示。关联助攻奖励按阶段大小解析，不将隐藏计数器的占位目标当作勋章要求。

## 更新资料

将固定版本的 `unlocks.blkx`、`unlocks_medals.csv`、`unlocks_conditions.csv` 放在被忽略的本地目录，运行：

```sh
node scripts/prepare-player-medal-details.mjs artifacts/medals-current
pnpm run check:data
```

整理脚本只读本地原始文件，逐个校验固定哈希；不联网采集或发布。更换来源版本时须同时核对图标注册表和解析规则。日常数据检查覆盖来源固定值、完整 ID 对齐、未知目标和关联助攻奖励等关键情况。

浏览器验收使用 `playwright-cli`，截图和验收资料仅保存在被忽略的 `artifacts/`。
