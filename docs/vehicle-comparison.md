# 载具装甲、弹药与完全体对比

科技树操作栏的“载具对比”位于折叠组按钮之后、缩放控制之前。先打开载具详情，使用“加入对比”；列表最多五辆，首辆锁定军种。陆军、航空、直升机、远洋海军、近海海军分别比较，其他军种的详情不显示加入入口。相同军种可以跨国家加入，不自动下载其它国家资料。

对比列表在当前工作台会话内保留，切换国家或页面不清空；刷新页面后重新选择，不写入账号、队列或地图存储。窗口根据载具数量使用紧凑列宽，卡片内展示国旗、国家，卡片下展示等级及已核验整包价格。每辆卡片旁直接移除，无需勾选；“设基准”将所选载具移到首列，其他载具维持原顺序，差值立即按新基准计算，弹种按载具身份保留。差值紧随数值同行展示。删除基准后首辆剩余载具成为新基准；全部删除后解除军种限制。

## 数据口径

- 仅读取 Wiki `spaded` 完全改装端点，使用明确的 AB／RB 模式。不替换成初始、专家或王牌值，不叠加乘员收益；来源未列值显示“—”。
- 非武器性能行按指标 ID 和单位匹配；武器性能按指标种类、单位和武器角色匹配，不能把页面中的第一个装填指标当成主炮。主炮、主机枪、同轴机枪、附属机枪分别处理，无法明确对齐的多重武器保持独立。缺少主炮值时不取机枪代替。地面扩展 v2 从独立来源补齐固定装填值，已有性能中的明确值或明确未知不被旧原件覆盖。保留武器名和来源测定高度，不把不同单位静默混为一项。
- 坦克详情的“性能数值”下依次展示车体／炮塔正侧后的标称装甲与武器弹药。标称厚度不代表复合装甲、反应装甲的等效防护。
- 弹药表保留类型、初速、弹重、装药与 TNT 当量；穿深只展示 500／1,000／2,000 米，原始距离数据仍完整保留。选择弹药后直接展示参数与来源射角表，不依赖悬停。图标宽高同时约束，避免细长弹种撑高行。
- 地面载具对比可分别选择弹种。默认“来源表格”沿用 Wiki 主表；选择 0°／30°／60° 时只读取来源明确列出的数值，不用其它角度填补。
- 装甲类型展示来源明确列出的复合装甲、反应装甲；没有型号或材料证明时不推测。已撤下默认 0°／系数 1 的单层估算及手动假设面板，不能把标称厚度重复显示成等效防护。现有结构化资料不足以计算真实车体／炮塔正面等效值，缺少可靠结果时不显示猜测数字，参见[修正记录](armor-estimation.md)。
- 详情增加“装备与模块”：动力、防护、火控、观瞄、雷达／光电及告警系统，另有只读配件模块目录。雷达展示型号、频段、TWS、敌我识别等明确能力；未明确写出的 AESA／PESA／脉冲多普勒体制不从型号猜测。模块目录不改变账号研发进度。
- 飞机／直升机详情的挂载、装备页以及对比页列出支持挂载的武器与设备。复用已有挂点表与固定预设，合并相同型号的重复数量项，保留同一武器 ID 下的不同型号和组合挂架。按现有武器类型归组，显示原官方图标与中文名称；悬停、键盘聚焦或触屏点击整项打开共享顶层详情，参数与来源在弹层内展示。主清单移除重复说明与来源行。不累加数量冒充可同时装配量，不为清单发起新国家数据请求。

## 资料准备与检查

复用现有匿名 Wiki 采集原件及解析模块，未新增采集器或定时任务。扩展存于 `performance.groundCombat`，沿用国家 CSV JS 模块、IndexedDB、哈希更新与 `vehicleStore`。每份地面扩展保留独立来源 URL、真实采集时间、原件哈希和 `wiki-ground-combat-v2` 解析版本，固定装填保存在对应武器的 `reload` 中。

2026-11-04 离线核验原件覆盖 1,225 辆地面载具：装甲 1,225 份，弹药表 1,215 份，2,879 个武器条目、6,059 条弹药／弹链记录。其余十辆为 Wiki 未列武器的火控／雷达载具。原始页面采集于 2026-10-24，离线补解析不冒充新采集时间。固定装填时间使用页面公开值，未注明的专家／王牌状态保持未知。

`scripts/prepare-ground-combat.py --archive <已有归档> --report-dir artifacts/<核对目录>` 只核对原件与生成本机报告；核对后通过 `--write` 更新 canonical JSON。已有完整性判断包含地面扩展，后续同页解析继续输出它。资料发布仍走既有管理员核对流程，不随离线准备自动上线。

增加 `--include-equipment` 可同时补解析所有军种的 `performance.equipment`，使用独立的 `wiki-vehicle-equipment-v1` 来源证明；本次覆盖 3,236 辆载具，仍复用 2026-10-24 原件，新增请求零次。已有较新性能原件时保留其原值与来源，设备扩展独立记录证据。

常规 `check` 包含 `check:vehicle-compare`，覆盖五辆上限、重复与跨军种拒绝、基准变化、直接删除、完全体取值、未知／零值和射角隔离。数据检查校验装甲、弹种、设备、数值、官方图片和来源结构；构建检查核对所有国家传输的完整性。
