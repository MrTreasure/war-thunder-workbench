# 国家载具资料加载（schema 4）

## 资源与版本

Canonical 资料仍在 data/*.json。每国只生成一个完整 JS 资源：
`export default <CSV 字符串的 JSON 字面量>;`，继续使用 QMuse 现有国家模块发布路径。
CSV 保留五军种科技树、全部载具字段、配件及费用、收益、性能、挂载和追加式分享编码。
HTTP 压缩由既有托管层协商 gzip/Brotli，不发布独立 CSV、JSON 或 gzip 文件。

CSV 是固定三列 type/id/value 的类型关系表，字段布局使用字典，相同子结构共享引用，
保留字符串、数字、布尔、null、空对象和空数组；单元格不嵌入整段 JSON。
JS 正文与解封装 CSV 分别有 SHA-256/字节数校验；远程 JS 只按固定字面量解析，不执行。
应用内同格式国家模块继续按国家原生动态 import，不预加载载具正文。

全局检查时间和全局来源索引作为清单元数据，不参与国家内容版本。
后台虽然可以选择字段更新，生成和缓存的物理资源仍是完整国家包；未变国家哈希不变。
清单 schema 4 仅接受 csv-js-v1，拒绝旧格式，不维护旧资源读取或缓存迁移逻辑。

## 缓存与共享实例

vehicleStore 是全站唯一公共载具实例，维护国家快照及载具 ID 索引。
科技树、车库、队列和折扣目录都从同一个国家快照派生；拥有状态与私人计划独立保存。
一个国家包含所有数据，切换军种、打开配件和详情不追加载具数据请求。

1. 优先返回内存对象，否则读取 IndexedDB 已解析快照；不重新解析 CSV。
2. 有本地资料立即展示，后台检查版本；相同哈希不下载国家正文。
3. 无本地资料时先读取服务端清单，服务暂不可用则使用应用内同格式已验证模块。
4. 新版本匿名 GET，验证 JS/CSV 后解析，IndexedDB 单事务写入整国数据及版本。
5. 事务完成后整体替换内存快照。网络或校验失败保留旧的有效版本。
6. IndexedDB 不可用时仍使用 GET 缓存与内存，不写大包 localStorage。

版本检查在进入相关页面和恢复前台时触发，60 秒内合并。同源部署解析优先使用专用 Worker。
QMuse 页面与静态资源分属不同源，直接使用带哈希校验的主线程解析；不构造跨域 Worker。
Worker 创建或运行失败也回退解析，IndexedDB 缓存与完整性校验保持一致。
数据库为 wt-vehicle-catalog-v3，每国一条原子记录。

## 本次旧数据清理

首次使用新版本清除 war-thunder-data-v1 OPFS 目录、wt-data-cache-v1:* localStorage、
旧公共 vehicles-* 与 research-catalog 缓存、旧 v1/v2 载具 IndexedDB。
不删除账号、购物车、研发计划、队列、地图方案或其他公共资源。
不能清理的来源保留重试状态，不把旧记录用于新加载器。
旧国家 JS 与轻量 vehicle-facts 模块从构建和新发布资源中删除，其他应用资源不变。
浏览器自行管理的 HTTP 缓存不能通过页面强制逐项删除；新版本不再引用旧数据地址。

## 管理与发布

后台按国家、军种和字段选择采集；发布范围单独选择并参与 planHash。
只修改确认字段，再生成受影响国家完整资源，不将字段选择变成多个下载包。
保持原件复用、来源证明、匿名读取、并发/间隔、限流停止规则。
新 JS 上传与校验后切换清单；清理仅匹配项目国家数据命名范围，保留清单当前十国对象。
预览独立发布，正式服务/索引切换等待用户确认。

## 基准

scripts/benchmark-vehicle-data.mjs 固定十国输入哈希，记录原始大小、压缩、解析 p50/p95。
浏览器用 playwright-cli 在独立 localhost 页面测旧缓存与新 IndexedDB/共享实例，
并检查升级清理范围、本地先返回、相同版本不下载、失败保留和单国请求合并。
输入和报告在忽略的 artifacts/vehicle-loading-benchmark-20261028/，不含账号或游戏请求。
测量不含公网延迟或渲染，不冒充视觉验收；不执行全量边缘检查。
