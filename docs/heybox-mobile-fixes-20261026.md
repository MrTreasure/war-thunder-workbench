## 截图 API 与验收边界

SDK 从正式 0.9.1 起默认叠加水印，当前使用 0.9.3。新画布底部保留 64 逻辑像素（平台要求至少 57），深色背景使用 `watermarkTheme: dark` 的白色水印。不按 DPR 乘坐标，使用全窗口默认区域；SDK 返回值不透明，不据此宣称相册保存或发帖成功。系统按键截图不属于此 API。

浏览器及 SDK Mock 使用明确虚构的玩家资料；头像演示图片为测试替身。它们不代表真实小黑盒登录、原生相册成图或发布成功。最终原生保存结果、胶囊左侧触摸命中仍需真机确认。

本机详细回执及截图保存在被忽略的 `artifacts/heybox-fixes-20261026/`；不包含在源码发布包。
