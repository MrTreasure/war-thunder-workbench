# 弹药原理动图

## 资料与发布

- 来源是用户提供的 78 个游戏原始 `shells_animations/*.ivf`，原件保存在本机忽略目录；不从教程或新闻视频截取。
- 原件均为 AV1、800×200、30 fps。AVIF 使用 `-c:v copy` 直接封装，保留原始帧与时序；MP4 是 H.264 CRF 17 兼容副本，另存首帧无损 WebP 用于页面不可见及减少动态效果偏好。
- 转换入口：`python3 scripts/prepare-shell-animations.py <解压目录> <输出目录>`。输出保留原件 SHA-256、各格式 SHA-256、字节数、尺寸、帧率和帧数。
- 仅转换资源上传到既有 `MrTreasure/oss-files` 的 `war-thunder/shell-animations/`。文件名包含内容哈希，`data/shell-animations.json` 固定完整提交 ID，先发布资源再发布页面。
- 用户已选择公开 Git 图床，不限制外链，不接入自有 R2、Worker 媒体代理或签名服务；客户端优先 jsDelivr，失败使用固定提交的 GitHub 原始文件。

## 展示规则

- `ShellAnimation` 只放在所选弹药的详情中，不放进弹药列表、下拉选项、配件模块或载具对比表，不提供动图总览。
- 按已采集的弹种映射通用作用原理，不把示意动画当成某个型号的实测效果。APC/APBC/APCBC 的装药信息未知时不推断其是否为穿甲榴弹；复合弹链和未知类型不猜测动画。
- 默认自动循环播放 AVIF，不展示暂停、播放或兼容模式按钮；解码/传输失败自动回退到静音、内联、循环且无播放器控件的 MP4。
- 动图按原始比例铺满详情容器横向宽度，不限制在原文件的 800px 宽度。
- 只加载当前可见详情的动画；离开视口、后台标签页或系统启用减少动态效果时使用首帧，恢复后自动继续。
- 详情的配件模块，按本车弹药名称精确匹配官方弹药图标；存在歧义或没有图片时保留原配件图，图片失败也回退原图。研发费用和配件状态不变。

## 检查边界

- 记录每段原件与转换文件的校验信息；样例 AVIF 解码后的全部 397 帧与原件逐帧哈希一致。
- 常规类型、lint、数据与构建检查后发布独立预览，由用户检查播放效果；浏览器和真机播放不以构建成功代替。
