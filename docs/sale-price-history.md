# 折扣日历与我的购物车

1. 打开「折扣日历」，点击「添加载具」，按国家、军种、等级或名称筛选金鹰／礼包载具，点击加入。
2. 点击「我的购物车」。旧版关注列表沿用原存储与账号同步，不需要重新添加。
3. 勾选本轮购车计划。人民币与金鹰分别合计；同一个礼包商品只计一次整包金额。按原价合计；缺少原价和报价冲突不按零价结算。
4. 载具卡片、购物车金额与小计始终使用资料原价。活动售价不会覆盖原价，也不参与合计。
5. 点击「查看历史」查看30天、180天、1年或全部记录，历史价格。未来活动只提供日期窗口，不预测具体价格。
6. 「官方购买」跳转官方商城；金鹰载具在游戏内按实际购买资格确认。

## 如何理解价格

- **原价**来自既有载具资料（礼包使用整包常规人民币原价，金鹰载具使用常规GE价）。历史采集独立留存，不更新载具目录、科技树或购物车的报价。
- **已记录最低**仅覆盖已保存、同商品／币种／内容版本／购买条件的有效记录，不表示商品上市以来最低。
- 公告明确列出的售价按公告生效日期留存，并保留实际核验时间；返场价只作为对应活动期间的历史记录。
- 目录常规GE参考价、官方明确售价及带条件的公告推导分别标注；只有折扣百分比的公告不能补造逐车价格。
- 旧人民币快照无法确认礼包内容时独立保存，不能与当前内容版本强行拼线。首次采样显示「走势积累中」。
- 趋势图显示真实观测点，近邻采样以阶梯线连接；超过36小时的未采样区间断开。最低价按全部保存记录计算，明细最多显示最近4096次。
- 官方商店目前未提供本工具可使用的完整逐商品历史价格目录。本工具从可核实的今年公告与已有快照开始，后续低频积累。

## 保存与恢复

游客清单和勾选保存在本浏览器。登录后载具列表使用既有账号工作区；购车勾选按账号同步。网络失败保留本账号待同步记录，跨设备冲突须先导出再选择重新读取云端。切换账号不沿用上一账号的私人计划。

购物车支持移除撤销及清单导出。账号「云端数据」导出包含购车设置；删除云端计划时同时清除购车勾选。研发购物车、车库拥有状态和出击队列保持各自用途。

### 商品合并与历史缺口

同平台、同SKU、币种、地区与购买条件的记录只显示一个商品入口。商品内容版本保留在记录中，版本不同或间隔超过36小时不连线；不同SKU及捆绑条件不合并。只有原价快照时显示“历史低价待核实”，不把当前原价称为历史最低。已确认的官方促销单列优惠比例、时间、购买条件和来源；没有当时人民币金额时保持未知，不用现在的原价倒算。单件和组合包优惠分别展示。

历史读取有超时、失败提示和重试。各国资料分别就绪，无需等所有请求；已有摘要可先显示，完整记录后台更新。手机购物车保留共同载具卡片原价，减少重复字段并固定可达的关闭与合计栏。

官方公告解析与抓取维护在既有私有Go服务，匿名采集、按语义范围匹配目录中的SKU，不在前端公开采集实现或原始网页。新增商品沿用目录匹配流程；不能唯一匹配的保留待核对，不猜价格或参加资格。
