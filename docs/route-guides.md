## 手动采集

本次文档整理没有发起采集。续查旧合集前必须读取[采集停点](guide-collection-checkpoint.md)和持久化的 `articleRetryAfter`，冷却结束不等于站点验证已解除，不创建自动续查任务。

```sh
# 仅为采集器准备浏览器，不用于默认界面验收
pnpm exec playwright install chromium

# 确认真实可用来源后，手动更新图集摘要和合集
pnpm run refresh:guides --source='<已确认的HTTPS资料源>' --article-checks=0

# 手动核对补充合集；正文核查前先检查停点和冷却
pnpm run refresh:collections
```

- 图集提取串行访问，默认7秒、最短6秒；6小时内复用快照，滚动与文章检查有上限，不自动批量下载文章或高清图。
- 补充合集的页面、分页和正文接口串行访问，默认8秒、最短7秒，同样复用6小时目录快照。
- 验证码、登录要求或限流时停止；正文验证挑战后冷却24小时，`--force` 不解除冷却，也不用换入口或重试绕过。
- 失败或不完整响应不覆盖此前有效资料；已完整、有证据的正文不重复抓取。续查后更新停点。
- 目录检查时间、摘要核验时间、原帖编辑时间分别保留；编辑时间不能替代正文差异证明，首次导入不标成新发表。

原始页面、文章与配准材料仅存本机忽略目录。公开资源不发布全文、评论、临时签名或未核对内容。来源原件入私有资料库也不等于授予匿名公开读取权限。

## 走线重新导入

已核对矢量经 `scripts/import-map-recommendations.py` 校验并生成规范候选：底图身份、任务点位、出生方向、几何与安全 SVG 白名单必须通过。未知地图不投到相近地图，单向素材不伪装为双向完整，保留来源日期和原始配准证明。

续采仅使用 B站、官方论坛及其合格视频来源、百度贴吧等用户明确允许的渠道；小黑盒已被用户取消，不因旧采集停点恢复访问。使用 Playwright 正常页面，串行至少 8 秒，遇登录、验证码或限流立即停在该站。引用日期不能代替所链视频的首次发布日期。

2026-11-05 用户指定“战雷走线教程”和“战雷阜南大学习”两个合集，并明确不按年份排除，覆盖此前只接受2025年以后视频的限制。本轮包含2024年原发视频；逐条保留原发时间、历史布局及现版通行性未知状态。目录、字幕、关键帧和已配准图稿分别计数，历史来源入库不代表已经适配当前地图。续作范围与缺口见[合集补采停点](map-season-collection-checkpoint.md)。

同一地图、布局及出生侧允许多种打法，按独立攻略 ID 保存，不覆盖已有方案。必须区分连续出击、换边、换车和剪辑；游泳或其他特殊通路应注明原片可证明的载具适用条件。只含单点或射界的材料可作为补充，不命名为从出生开始的完整走线。

每个方案保留纯矢量、文字攻略、来源与时间码、提取文字、配准坐标及依据状态。小型 SVG 存既有地图数据库，底图继续使用既有 CDN，不把带底图的 Base64 合成 SVG 重复入库。自己的演示路线、对侧演示通道作为敌军预判，以及地形推演必须明确区分，未知频率和到达时间保留为空。图稿获确认后才写入相应资料版本，后续新采候选不自动发布。

### 视频小地图提取流程

1. 在已授权的正常浏览器页面核对作者、首次发布日期、地图、任务布局及出生侧。登录由用户完成，会话仅保存在本机私有位置；遇验证或限流停止。
2. 先用少量原生关键帧确认地图纹理、任务点和出击切换。需要加密路线时，正常倍速播放一次，定时从已解码视频截取本地小地图裁片；不用反复跳时、媒体直链或下载器。
3. 每帧记录实际视频时间、视频原生尺寸、裁片矩形、缩放、原件哈希与坐标矩阵。视频分辨率变化时逐帧换算，不沿用上一帧像素坐标。
4. 离线图像处理识别自车标记并匹配静态地形。将未参与拟合的原始关键帧作为独立检验，分别报告地形匹配残差、自车识别误差及其单位；无法证明的完整地图 UV 误差上限留空。启发式置信分数不称为正确概率。
5. 登录界面、计分板、炮击选区、遮挡、歧义、边缘截断和异常位移保持空白。换车、重生及地面转飞行分别建段，不因标记颜色相同就认定同一车辆。视频时间码不是实际驾驶耗时。
6. 保留全部原始点与拒绝原因，仅在各可靠段内部简化绘图，不能跨缺口插值。模型只查看必要的少量校准裁片，其余由本机图像处理批量提取。记录实际采集及处理耗时；无法取得的 token 和费用为 `null`，不从帧数估算。

提取节点完成自车身份核查后，才提供带轨迹哈希的最终确认记录。绘图节点验证该哈希，不读取仍在生成的中间轨迹；据点亮色碎片、友军或出生符号疑似误检必须先拒绝或复核。待审清单只收入已确认的图稿，压缩包先完整写入临时文件再原子替换，避免把处理中资料当作成品交付。

### 完整方案与绘图语义

完整攻略说明出生接近、首次接战、中后程决策、敌方可能来向和回撤条件。来源车线不足的部分，可依据清晰可见道路编写有条件的地形规划；明确标注推演，不声称原作者实际走过。未知门洞、桥梁、涉水点及地形高度不补成已验证通路。

| 图示 | 含义 |
| --- | --- |
| 绿色实线 | 有来源位置或作者明确走线依据的我方路线；具体依据另存 |
| 绿色点线 | 根据地形整理的我方接入或后续规划 |
| 红色虚线／点线 | 来源通道或地形推演的敌方可能来向，分别记录依据 |
| 黄色箭头 | 需要观察的位置或方向，不保证无遮挡射界 |

作者的射界、支援关系及不推荐站位不能改画成推荐行车路线。浮渡等特殊通路逐条记录车型适用证据；不同出击不互相继承能力。历史方案保留来源时期、改版差异与当前可通行性未知状态，不冒充现版实测。

交付包含原始坐标体系下的透明 SVG、高清底图合成图、文字攻略和可公开的来源元数据。数据库保存小型透明 SVG 与结构化文字；合成图、原始页面和视频裁片不重复塞进 SVG 字段。待审包排除会话、原始页面、本地路径及私有服务资料。新候选与已验收入库的数量分别报告。

提取或导入只更新候选资料，不发布。运行 `pnpm run check`、`pnpm run build` 后，由管理员核对并按授权发布对应数据版本；网站预览和正式资料索引是不同发布范围。

## 旧高清图与缓存

旧图集可经 `/map-catalogs/legacy-hd` 读取图片和缩略图地址，具体响应见 API 文档。缩略图按需读取，原图在明确打开后下载，核对字节数与哈希。浏览器旧图缓存目录 `wt-map-atlas-v1` 与地图公开快照、走线会话缓存、国家资料和用户方案分开，清理图片不删除其他状态。
