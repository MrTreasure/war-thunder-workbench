## 手动采集

本次文档整理没有发起采集。续查旧合集前必须读取[采集停点](guide-collection-checkpoint.md)和持久化的 `articleRetryAfter`，冷却结束不等于站点验证已解除，不创建自动续查任务。

```sh
# 仅为采集器准备浏览器，不用于默认界面验收
pnpm exec playwright install chromium

# 确认真实可用来源后，手动更新图集摘要和合集
pnpm run refresh:guides --source='<已确认的HTTPS资料源>' --article-checks=0

# 手动核对补充合集；正文核查前先检查停点和冷却
pnpm run refresh:collections
```

- 图集提取串行访问，默认7秒、最短6秒；6小时内复用快照，滚动与文章检查有上限，不自动批量下载文章或高清图。
- 补充合集的页面、分页和正文接口串行访问，默认8秒、最短7秒，同样复用6小时目录快照。
- 验证码、登录要求或限流时停止；正文验证挑战后冷却24小时，`--force` 不解除冷却，也不用换入口或重试绕过。
- 失败或不完整响应不覆盖此前有效资料；已完整、有证据的正文不重复抓取。续查后更新停点。
- 目录检查时间、摘要核验时间、原帖编辑时间分别保留；编辑时间不能替代正文差异证明，首次导入不标成新发表。

原始页面、文章与配准材料仅存本机忽略目录。公开资源不发布全文、评论、临时签名或未核对内容。来源原件入私有资料库也不等于授予匿名公开读取权限。

## 走线重新导入

已核对矢量经 `scripts/import-map-recommendations.py` 校验并生成规范候选：底图身份、任务点位、出生方向、几何与安全 SVG 白名单必须通过。未知地图不投到相近地图，单向素材不伪装为双向完整，保留来源日期和原始配准证明。

2026-11-01 本轮续采仅使用 B站、官方论坛及其合格视频来源、百度贴吧等用户明确允许的渠道；小黑盒已被用户取消，不因旧采集停点恢复访问。使用 Playwright 正常页面，串行至少 8 秒，遇登录、验证码或限流立即停在该站。原始发布需为 2025 年及以后，引用日期不能代替所链视频的首次发布日期。

同一地图、布局及出生侧允许多种打法，按独立攻略 ID 保存，不覆盖已有方案。必须区分连续出击、换边、换车和剪辑；游泳或其他特殊通路应注明原片可证明的载具适用条件。只含单点或射界的材料可作为补充，不命名为从出生开始的完整走线。

每个方案保留纯矢量、文字攻略、来源与时间码、提取文字、配准坐标及依据状态。小型 SVG 存既有地图数据库，底图继续使用既有 CDN，不把带底图的 Base64 合成 SVG 重复入库。自己的演示路线、对侧演示通道作为敌军预判，以及地形推演必须明确区分，未知频率和到达时间保留为空。图稿获确认后才写入相应资料版本，后续新采候选不自动发布。

提取或导入只更新候选资料，不发布。运行 `pnpm run check`、`pnpm run build` 后，由管理员核对并按授权发布对应数据版本；网站预览和正式资料索引是不同发布范围。

## 旧高清图与缓存

旧图集可经 `/map-catalogs/legacy-hd` 读取图片和缩略图地址，具体响应见 API 文档。缩略图按需读取，原图在明确打开后下载，核对字节数与哈希。浏览器旧图缓存目录 `wt-map-atlas-v1` 与地图公开快照、走线会话缓存、国家资料和用户方案分开，清理图片不删除其他状态。
