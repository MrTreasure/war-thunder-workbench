# 模拟挂载

入口为 `#/loadouts`，仅登录用户可进入模拟、保存与发布。科技树中有可用挂载资料的航空／直升机详情提供“挂载推荐”页签与模拟入口。

## 使用流程

1. **我的挂载**：进入页面先显示账号已保存的挂载。正式方案保存在远程账号工作区，本机只保留按用户隔离的未完成草稿。最多保存 100 套。
2. **添加挂载**：打开选机弹窗，按有官方国旗的国家选择、等级、名称筛选，以共用载具卡片选择机型。没有可用挂载表或预设的候选隐藏；取消选机不修改当前方案。
3. **配置挂载**：自定义挂载区域占满一行，当前挂载汇总另占一行。挂点名称支持换行；没有来源选项的点明确禁用，已确认冲突的候选显示原因。支持撤销、重做、清空、重新选择机型及返回列表。重新选机清空当前编辑中的挂载，再次保存前原已保存方案保持不变。
4. **默认与预设**：展示 Wiki 提供的完整 Setup，按整组应用，不将不同预设拼接。资料只有挂点矩阵时明确提示默认预设未提供；不把空挂载或第一个选项冒充游戏默认方案。
5. **按挂载找机型**：选择具体武器及最低数量，按国家、等级、军种筛选。多个条件同时满足；计算预算不足和资料不足分别提示，不能据此判断绝对无解。
6. **发布到大厅**：复用队列的标签选择器，选择 1～5 个目录中的标签与基础样式。发布记录会同时关联对应机型的“挂载推荐”。公开标题由载具标准名称生成，私人方案名称保留在自己的云端记录中。最多保留 100 条推荐；撤回后大厅及机型推荐同步移除。

用户已暂缓分享码与外部分享链接。当前不提供生成／复制分享码或链接；仅支持应用内大厅、推荐关联，以及本人备份文件导入导出。打开大厅方案会核对当前来源，显式保存后才成为自己的方案。

## 信息与来源

武器类别、常见单位与制导信息优先中文，型号和原始名称保留；中英文均可搜索。参数、限制与来源说明直接展示，不依赖悬停或折叠。展示翻译不改变来源、匹配标识和方案内容身份。

挂载数据与科技树共用国家 CSV JS、`vehicleStore` 和 IndexedDB；选机后才读取所选国家的完整文件。列表使用账号记录与服务端紧凑卡片资料，不为查看保存列表下载所有国家包。

既有基线 1,181 个机型有挂载记录，其中 748 个有挂点矩阵、433 个有固定预设；255 个航空／直升机未提供可用资料。原页面采集时间主要为 2026-10-24，本次功能与规则更新不冒充重新全量采集。未提供不表示游戏中没有挂载。

校验同挂点冲突、公开数量、组合重量、总挂重、单翼挂重、两翼差值与明确来源的互斥规则。未公开的跨挂点限制、对称与个人配件解锁仍为未知；“已知规则通过”不表示完整复现游戏校验。挂点示意保留来源顺序与翼侧，不声称真实比例。

编辑时固定资料快照；新版本由用户载入并核对。旧项失效保留冲突提示，不能按新表格行号猜测替换。大厅发布在服务端再次校验机型、挂点、选项、来源版本及标签，不信任客户端的通过声明。

## 维护

- 复用现有 Wiki 采集、`scripts/wiki-vehicle-reference.py` 解析与国家发布链路，不另建采集器。额外公开规则保存在 `data/loadout-rules.json`。
- 挂载刷新作为既有每日检查的可选步骤，默认关闭；新载具身份与科技树结构仍走既有核对。失败保留现行值和来源时间。
- 当前交付为独立预览，账号挂载、发布及撤回写入隔离数据库。正式站与自动更新启用等待预览确认。
- `pnpm run check:loadouts`、常规检查与构建属于代码门槛；前端验收由用户自行进行。私有运行及接入细节不在公开文档维护。
