# 效率评分

规则版本：`wt-efficiency-v2`。评分范围：**0–2000**。这是用于阅读公开战绩的统计指标，不是官方评级，也不代表全服名次或百分位。

## 计算公式

设 B 为战斗场次，W 为胜场，D 为死亡，K 为同一统计范围内已返回的各类击毁之和。

```text
c = 70.42816122818694
kd = K / (D + c)
kb = K / (B + c)
wr = (W + 0.5 × c) / (B + c)

z = 0.7508205179665183 × ln(kd)
  + 0.48839115040457637 × ln(kb)
  + 0.32506239005447524 × wr
  − 1.1223470837701672

效率 = round(2000 / (1 + exp(−z)))
```

ln 是自然对数；wr 使用 0–1 小数；结果四舍五入为整数。参数与界面说明统一保存在 [player-stats-rules.json](../data/player-stats-rules.json)。

## 边界与范围

- 少于 50 场，评分为 0，并标注场次不足。
- 已知击毁合计为 0，评分为 0。
- B、W、D 或全部击毁计数缺失，显示“—”；无效计数或胜场超过场次不评分。
- 未返回的目标类别保持未知，只合计已返回的击毁，不将未知当成已确认的零。
- 页面直接展示的 K/D 保持“原始击毁 ÷ 死亡”；公式内部的平滑值只用于评分，不替换原始 K/D。
- 生涯总览使用该模式的生涯计数；单车使用该车计数。Top 5 汇总仍是所列载具的统计，不能把多车场次之和称为玩家总对局。

## 缓存与战报

有效缓存返回时按当前规则计算派生评分，不额外查询官方、不消耗新查询次数，也不修改原始快照和缓存时效。

点击“强制刷新”会重新获取官方资料，成功后按一次新查询计入对应身份额度。每位用户对同一玩家每分钟可刷新一次；仍遵守官方请求间隔与异常调用限制。刷新失败保留原资料并释放占用的次数。

新战报使用当前规则，历史战报保留生成时的评分版本与图表量程。陆战筛选隐藏对海列；纯陆战战报隐藏海上目标击毁构成与单车对海 K/D。
