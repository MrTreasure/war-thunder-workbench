# 效率评分

当前版本：`wt-efficiency-v3`，展示范围 0–2000。这是工作台的统计评分，不是官方评级、全服名次或百分位。

## 影响指标

击毁与死亡表现、场均击毁、每次出击击毁、胜率、场均死亡、场均出击及记录场次。陆战与航空不计海上目标击毁。少于 50 场记 0，缺失关键记录时不评分；未知数据不当作零。

## 计算与缓存

私有 Go 服务统一计算生涯、模式、军种、载具和战报的效率值，将结果与评分版本保存到资料缓存。缓存命中直接返回已有评分；历史资料首次读取时升级派生评分，不重新查询官方、不改变原始采集时间、不消耗查询额度。服务重启后仍可复用数据库中的评分。

前端、载具卡片和战报图片只展示接口结果，不加载 WASM，也不包含计算公式或浏览器计算回退。离线资料保留最后一次获取的服务端评分，联机读取时由服务端检查评分版本。

## 授权与维护

评分实现及研究材料受作者保护，仅在本机私有服务维护，不包含在公开仓库、应用源码包或静态资源中。公开规则仅说明影响指标，不披露具体计算逻辑。

## 数据与战报

缓存时效和原始采集时间保持不变。强制刷新成功后按身份额度计数，失败保留原资料。AI 战报使用同一服务端评分，不信任客户端提交的评分。

K/D 展示继续使用同一统计范围的原始记录，与效率评分分开。载具统计汇总不等于玩家的真实对局总数。
