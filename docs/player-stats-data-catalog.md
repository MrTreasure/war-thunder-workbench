# 战绩查询可用数据清单

核对日期：2026-10-21。依据两名玩家的官方助手实际公开资料响应整理，查询链路已验证。此处“已返回”表示取得过真实数据，不表示所有字段口径都已在游戏界面核对。

## 一、已经取得的数据

| 类别 | 已取得内容 | 展示时的边界 |
| --- | --- | --- |
| 玩家搜索 | 候选昵称、玩家 ID、头像标识 | 前缀搜索可能返回多个玩家；大小写不同的昵称可能对应不同 ID，必须明确选人 |
| 基础资料 | 昵称、玩家 ID、等级、称号标识、头像标识 | 称号与头像要通过对应资源解释；不推断未返回的联队 |
| 等级经验 | 当前等级经验、该等级的经验目标、进度数值 | 玩家等级经验与载具研发点分开；不是当前研发进度 |
| 主页装饰 | 头像框、主页背景标识 | 部分账号没有对应字段；标识不代表图片地址已经检查可用 |
| 主页展示 | 展示类型标识、展示载具 ID | 样本返回 favorite_unit 与对应载具 ID；不等于完整车库或最多使用的载具 |

| 兵种游玩时长 | 已知兵种的累计时长字段，如战斗机、轰炸机、攻击机、坦克、重坦、坦歼、防空 | 完整兵种映射尚未补齐，不把现有部分时长强称为完整总时长 |

| 评分与排名 | PVP 评分、多项排行榜数值及排名，包括平均相对位置、平均得分等候选指标 | 字段已经取得，具体指标对应及两组榜单的时间窗口仍需核对；不直接写成月榜或最近 30 天 |
| 部分死亡统计 | 排行榜死亡字段与单车死亡字段 | 某些模式的排行榜无有效值；不能用单车合计静默替换原字段 |

### 样本中观察到的差异

基础战绩、排行榜和单车记录之间存在部分计数差值，原因尚未核对。展示时应保留来源区块，不能通过增删记录强行凑出相同总数。`-1`、`-2` 等无数据标志不可显示为实际成绩。

## 三、基于已知字段可计算的内容

这些是本工具计算结果，应与官方直接返回的字段区分。

- 胜率：有效胜场 ÷ 有效场次。
- 空中或地面击杀/死亡比：对应击杀 ÷ 同一统计范围的死亡数；没有死亡数据时不计算，死亡为零时不能显示成零比值。
- 场均击杀、每次出击的击杀表现：仅在分子分母属于同一统计范围时计算。
- 精英比例：同一国家的精英数 ÷ 拥有数，两个数都必须有效。
- 单车排行、常用载具列表：依据有效单车记录排序，并说明属于有记录的载具。
- 每次出击击杀（参考图称 K/R）：同一范围的击杀 ÷ 出击次数，与场均击杀分开。
- 兵种表现：对能匹配车型的单车记录按类别汇总，再计算每次出击击杀；标明车型匹配覆盖与缺项，不能用总体击杀和某兵种时长推出该兵种表现。
- 时间区间内的变化：今后保存有日期的累计快照再比较；不是逐场记录，也不能补出接入之前的历史。

## 四、可从现有载具库补充的信息

对能匹配现有载具 ID 的记录，可以补上游戏简体中文名称、国家、类别、等级、各模式战斗评级和官方图片。它们来自项目已有载具资料，不能当作本次查询取得的玩家研发、购买或配件状态；未匹配的旧 ID 保持原样。

## 五、目前没有确认能获取的数据

- 完整已购载具 ID 清单，以及未出战载具的准确购买状态。
- 当前银狮、金鹰余额和净收益。
- 当前研发载具、已投入研发点、配件解锁进度。
- 每场对局的时间、地图、队伍、详细收益和回放对应关系。
- 准确注册日期、最近登录时间、在线状态。
- 联队完整资料、成员名单及其活动明细。
- 完整勋章、成就和收藏清单。公开资料的国别计数不能冒充勋章数量。
- 已购数量按类别、等级的完整拆分。

以上表示“本轮尚未验证”，不表示官方其他服务一定不存在这些数据。其他服务需要逐项研究，不能从当前公开资料响应推断可用性。

## 六、当前适合优先展示的范围

玩家资料、等级进度、模式战绩、各国载具数量、单车战绩和常用载具。收益保留为待确认项；评分及排名保留口径说明。查询会话、原始样本与来源时间应由独立服务管理。

详细链路与证据见[战绩查询调研](player-stats-research.md)。原始公开样本留在被忽略的研究目录，密码、验证码和登录凭证不写入该清单。
