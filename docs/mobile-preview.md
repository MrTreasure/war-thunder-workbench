# 移动端适配预览

先运行 `pnpm run build`，再运行 `pnpm run preview`。浏览器打开 `http://localhost:4178/#/tree`；同一局域网的手机可将 localhost 换成运行项目的电脑地址。

## 本次调整

- 800px 及以下（触摸设备放宽至 1100px）：顶部操作默认收起，显示国家、军种、模式和搜索状态。展开后可选择国家、军种、权重和载具类型，进行搜索、研发、购物车、缩放与全屏操作。
- 展开的面板可上下滚动，点击“收起并查看科技树”回到树；搜索定位后自动收起。桌面继续直接显示工具。
- 载具与配件研发改为单列滚动，载具报价汇总置顶，关闭按钮一直可达。输入框和常用按钮适合触摸，修改基础 RP 时采用两行排布。
- 详情大图、购物车、队列导入与分享窗口适应屏幕宽度。
- 国家首页改为双列；队列列表、配置表单和选车列表适应小屏，乘员槽位保留一横排及拖动操作。
- 手机顶部右侧的创作入口缩为“创作工具”。

## 手动验收

建议查看 320、375、414、768px，以及 1440px 桌面宽度：

1. 未选择国家时，可浏览全部十国；选定国家后，科技树可上下及左右滚动。
2. 顶部收起、展开、切换国家和军种、组合筛选、搜索定位均可用；关闭展开面板不会清除筛选。
3. 展开后可打开两种研发面板和购物车；键盘 `/` 展开搜索，`Esc` 收起并返回按钮。
4. 载具研发可修改目标、单价、计价起点，展开已有载具及补研筛选，编辑基础 RP 并滚动查看结果。
5. 配件进度、详情图片、购物车清单、队列分享码不会撑宽整个页面；窗口关闭按钮可触达。
6. 队列可新建、编辑、取消和保存；长名称正常换行，乘员槽位横向滑动和长按拖动正常。
7. 手机键盘打开、横屏、浏览器地址栏收起后，输入框与关闭按钮仍可操作。

已完成代码、类型、数据与构建检查，并检查了 320、375、414、768px 下的页面宽度、筛选展开收起和主要弹窗；真实手机的触摸与键盘体验仍可按上表验收。
