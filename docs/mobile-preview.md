# 移动端适配预览

预览地址：[打开移动端交互预览](https://render.mrtreasure.cc/muse/war-thunder-trees/#/tree)。

通过现有 Nginx 服务展示完整构建产物，手机可直接访问。先运行 `pnpm run build`，通过检查后执行 `pnpm run publish`，将产物更新到原有预览路径；入口自动备份，旧哈希资源保留。QMuse 导入另行确认。

## 本次调整

- 800px 及以下（触摸设备放宽至 1100px）：顶部操作默认收起，显示国家、军种、模式和搜索状态。展开后可选择国家、军种、权重和载具类型，进行搜索、研发、购物车、缩放与全屏操作。
- 两页共用同一个顶部栏，切换时只更换下方内容，标志、标题和创作入口保持原位。桌面显示“科技树 / 出击队列”导航；手机通过最顶部的下拉框切换页面，独立于筛选面板。军种标签采用游戏菜单名称：陆军、空军、直升机、远洋海军、近岸海军。
- 展开的面板可上下滚动，点击“收起并查看科技树”回到树；搜索定位后自动收起。桌面继续直接显示工具。
- 载具与配件研发改为单列滚动，载具报价汇总置顶，关闭按钮一直可达。输入框和常用按钮适合触摸，修改基础 RP 时采用两行排布。
- 详情大图、购物车、队列导入与分享窗口适应屏幕宽度。
- 国家首页改为双列；队列列表、配置表单和选车列表适应小屏，乘员槽位保留一横排及拖动操作。
- 手机顶部右侧的创作入口缩为“创作工具”。
- 手机顶部的页面下拉框居中显示，去掉边框和底色；战雷标志使用原有浅色样式。科技树外层去掉左右多余留白，与顶部栏边缘对齐；极窄屏的创作入口仅显示图标。
- 队列页将国家、卡片权重和导入入口放在同一行，空列表只展示一个新建入口。已保存队列的分享紧邻标题，编辑与删除位于卡片底部；宽屏下标题和内容居中对齐。
- 队列配置保留横向乘员槽位和型号搜索，手机上的军种、等级与类型筛选按需展开，收起时显示当前筛选条件。复制与删除放在“更多操作”中，保存和取消直接可用。

## 手动验收

建议查看 320、375、414、768px，以及 1440px 桌面宽度：

1. 未选择国家时，可浏览全部十国；选定国家后，科技树可上下及左右滚动。
2. 顶部收起、展开、切换国家和军种、组合筛选、搜索定位均可用；关闭展开面板不会清除筛选。
   筛选收起后仍可通过顶部下拉框进入出击队列；队列页也可从同一位置返回科技树。切换前后顶部栏的位置和高度一致；浏览器前进、后退和刷新保留正确页面与滚动位置。
3. 展开后可打开两种研发面板和购物车；键盘 `/` 展开搜索，`Esc` 收起并返回按钮。
4. 载具研发可修改目标、单价、计价起点，展开已有载具及补研筛选，编辑基础 RP 并滚动查看结果。
5. 配件进度、详情图片、购物车清单、队列分享码不会撑宽整个页面；窗口关闭按钮可触达。
6. 队列可新建、编辑、取消和保存；长名称正常换行，乘员槽位横向滑动和长按拖动正常。
   同时查看无队列、已保存队列和编辑状态：新建入口没有重复，筛选收起后仍生效，分享、导入和卡片权重切换可用。
7. 手机键盘打开、横屏、浏览器地址栏收起后，输入框与关闭按钮仍可操作。

代码、类型、数据与构建检查用于确认产物完整；本次导航与文案调整的屏幕布局、触摸和键盘体验按上表手动验收。
