# 给战雷做了个查车配队工具，还能画走线

玩战雷时，经常想查一辆车还差多少研发、这个权重怎么配队，或者把走线画给队友看。

所以做了个中文小工具，把这些放到了一起，电脑手机都能打开，无需登录。

🗺️ **看地图，也能自己画战术图**

整理了 55 张陆战地图、309 种任务布局。可以搜地图、看等高线、切布局，对照占领点和出生点研究地形。

点“编辑走线”，就能画进攻箭头、平滑曲线、绿色防御阵线，也能标出狙击点、观察点和危险区域，配上文字说明。

线条拖出来就能改，颜色、粗细、拐点都可以调整。画错可以撤销，也能一键清除。画好后保存成 2K / 4K 图片，直接发给一起玩的队友。

🌳 **查科技树和研发路线**

十国载具，陆军、空军、直升机和海军都能查。支持搜型号、看前置、切战斗模式，也能点开载具看大图和资料。

🧮 **算还差多少研发**

填好已有车辆、已开放等级和已投入研发点，就能整理待研清单。配件也能单独勾选，已经完成的会扣掉。

费用可以自填单价，说明里用载具 3 元 / 万、配件 4 元 / 万举例，仅作计算演示。

🚩 **把常玩的队列存起来**

按国家保存多套队列，横向排列、拖动排序，查看不同模式的权重。点分享复制分享码，队友粘贴导入就能带入载具顺序。

截图里的配队和走线都是演示，不是最优打法。资料和分房规则以游戏内为准。

如果你也玩战雷，欢迎试试，也欢迎告诉我还想加什么功能。
